4. Structures de contrôle

if...else

if (condition) {
    /* bloc */
} else {
    /* autre bloc */
}

switch...case

switch(variable) {
    case 1: /* actions */ break;
    case 2: /* actions */ break;
    default: /* actions */
}

Boucles

  • for : itération contrôlée
  • while : test en entrée
  • do...while : test en sortie (exécution au moins une fois)

Instructions d'échappement

break : sortie de boucle/switch
continue : passe à l'itération suivante
return : sortie de fonction
goto : saut (à utiliser avec précaution)
