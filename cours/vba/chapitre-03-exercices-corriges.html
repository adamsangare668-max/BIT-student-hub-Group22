Exercice 1 – Compter les voyelles

Énoncé : Écrire un programme (Sub nombrevoyelles()) qui renvoie le nombre de voyelles contenues dans une chaîne de caractères entrée par l’utilisateur.

Correction

Algorithme :

  1. Demander la chaîne à l’utilisateur (InputBox).
  2. Initialiser un compteur à 0.
  3. Parcourir chaque caractère de la chaîne (boucle For de 1 à Len(texte)).
  4. Extraire le caractère avec Mid.
  5. Si le caractère est une voyelle (minuscule ou majuscule), incrémenter le compteur.
  6. Afficher le résultat.

Code VBA complet :

Sub nombrevoyelles()
    Dim texte As String
    Dim i As Integer
    Dim caractere As String
    Dim compteur As Integer

    texte = InputBox("Entrez une chaîne de caractères")
    compteur = 0

    For i = 1 To Len(texte)
        caractere = Mid(texte, i, 1)
        If caractere = "a" Or caractere = "e" Or caractere = "i" Or caractere = "o" Or caractere = "u" Or caractere = "y" Or _
           caractere = "A" Or caractere = "E" Or caractere = "I" Or caractere = "O" Or caractere = "U" Or caractere = "Y" Then
            compteur = compteur + 1
        End If
    Next i

    MsgBox "Le nombre de voyelles est : " & compteur
End Sub
Remarque : La fonction Mid(texte, i, 1) extrait un caractère à la position i. La boucle For parcourt toute la chaîne.
✔ Réponse : le programme affiche le nombre total de voyelles (a, e, i, o, u, y) dans la chaîne saisie.
Exercice 2 – Bulletin étudiant

Énoncé : Créer une macro BulletinEtudiant() qui demande : nom, filière, niveau, moyenne. Puis affiche : nom, filière, niveau, moyenne, décision et mention selon les barèmes fournis.

MoyenneDécisionMention
>= 10Admis—
< 10AjournéÉchec
>= 16—Très Bien
>= 14—Bien
>= 12—Assez Bien
>= 10—Passable

Correction

Algorithme :

  1. Demander les 4 informations avec InputBox.
  2. Vérifier que la moyenne est numérique (IsNumeric). Si non, afficher une erreur et sortir.
  3. Déterminer la décision (Admis si >= 10, sinon Ajourné).
  4. Déterminer la mention avec If...ElseIf.
  5. Afficher le bulletin complet avec MsgBox.

Code VBA :

Sub BulletinEtudiant()
    Dim Nom As String, Filiere As String, Niveau As String
    Dim Saisie As String, Moyenne As Double
    Dim Decision As String, Mention As String

    Nom = InputBox("Entrez le nom de l'étudiant")
    Filiere = InputBox("Entrez la filière")
    Niveau = InputBox("Entrez le niveau")
    Saisie = InputBox("Entrez la moyenne")

    If Not IsNumeric(Saisie) Then
        MsgBox "La moyenne doit être un nombre", vbCritical, "Erreur"
        Exit Sub
    End If

    Moyenne = CDbl(Saisie)

    If Moyenne >= 10 Then Decision = "Admis" Else Decision = "Ajourné"

    If Moyenne >= 16 Then Mention = "Très Bien"
    ElseIf Moyenne >= 14 Then Mention = "Bien"
    ElseIf Moyenne >= 12 Then Mention = "Assez Bien"
    ElseIf Moyenne >= 10 Then Mention = "Passable"
    Else Mention = "Échec"
    End If

    MsgBox "BULLETIN ÉTUDIANT" & vbCrLf & _
           "Nom : " & Nom & vbCrLf & _
           "Filière : " & Filiere & vbCrLf & _
           "Niveau : " & Niveau & vbCrLf & _
           "Moyenne : " & Moyenne & vbCrLf & _
           "Décision : " & Decision & vbCrLf & _
           "Mention : " & Mention, vbInformation, "Résultat"
End Sub
✔ La macro affiche un bulletin complet avec la décision et la mention appropriées.
Exercice 3 – TP : Macro FormatNotes

Énoncé : Enregistrer une macro FormatNotes qui met les titres en gras, centrés, ajoute des bordures et ajuste les colonnes. Puis modifier le code pour : taille des titres = 14, fond coloré des titres, bordures sur A1:C5, et ajouter un message de fin.

Correction

Version enregistrée (simplifiée) :

Sub FormatNotes()
    Range("A1:C1").Font.Bold = True
    Range("A1:C1").HorizontalAlignment = xlCenter
    Range("A1:C5").Borders.LineStyle = xlContinuous
    Columns("A:C").AutoFit
End Sub

Code modifié selon les consignes :

Sub FormatNotes()
    ' Mettre les titres en gras, taille 14, centrés
    Range("A1:C1").Font.Bold = True
    Range("A1:C1").Font.Size = 14
    Range("A1:C1").HorizontalAlignment = xlCenter
    ' Couleur de fond des titres (gris clair)
    Range("A1:C1").Interior.Color = RGB(200, 200, 200)
    ' Bordures sur A1:C5
    Range("A1:C5").Borders.LineStyle = xlContinuous
    ' Ajustement des colonnes
    Columns("A:C").AutoFit
    ' Message de confirmation
    MsgBox "Mise en forme terminée"
End Sub
Remarque : La modification de la macro permet d’adapter facilement la mise en forme sans la réenregistrer. L’ajout d’un message (MsgBox) rend l’exécution plus conviviale.
✔ La macro modifiée applique la mise en forme demandée et informe l’utilisateur.
Exercice 4 – Bouton "Calculer les moyennes"

Énoncé : Créer un bouton dans Excel qui exécute une macro CalculerMoyennes pour calculer les moyennes d’un tableau (CC, TP, Examen).

Correction

Macro à associer :

Sub CalculerMoyennes()
    Dim i As Long
    Dim DerniereLigne As Long
    DerniereLigne = Cells(Rows.Count, "A").End(xlUp).Row
    For i = 2 To DerniereLigne
        Cells(i, "E").Value = (Cells(i, "B").Value + Cells(i, "C").Value + Cells(i, "D").Value) / 3
    Next i
    MsgBox "Les moyennes ont été calculées"
End Sub

Étapes pour le bouton :

  1. Onglet Développeur → Insérer → Bouton (contrôle de formulaire).
  2. Dessiner le bouton dans la feuille.
  3. Dans la fenêtre "Affecter une macro", choisir CalculerMoyennes.
  4. Modifier le texte du bouton (clic droit → Modifier le texte) en "Calculer les moyennes".
✔ Le bouton déclenche le calcul des moyennes et affiche une confirmation.
