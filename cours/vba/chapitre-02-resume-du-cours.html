📘 Résumé du cours

🔹 Module 1 : Fonctions avancées Excel / Word

Fonctions logiques : SI(), ET(), OU(), combinaison SI+ET.

Fonctions de recherche : RECHERCHEV() (recherche verticale) et RECHERCHEX() (plus souple).

Statistiques : MOYENNE(), MAX(), MIN(), NB(), NB.SI(), MOYENNE.SI().

Texte : CONCAT(), GAUCHE(), DROITE(), STXT(), MAJUSCULE(), MINUSCULE(), NBCAR().

Outils Word : styles, table des matières automatique, en-têtes/pieds de page, publipostage (fusion Excel + Word).

🔹 Module 2 : Introduction aux macros

Macro : suite d’actions enregistrées et rejouables. Gain de temps, réduction d’erreurs, standardisation.

Activation onglet Développeur : Fichier → Options → Personnaliser le ruban → cocher Développeur.

Enregistrement : nom sans espace, pas de chiffre au début. Choix de l’emplacement (ce classeur, nouveau classeur, classeur de macros personnelles).

Exécution : via le menu Macros ou raccourci clavier (ex. Ctrl+Maj+M).

🔹 Module 3 : Introduction à VBA

VBA = Visual Basic for Applications, intégré à Office. Permet d’automatiser des tâches.

Algorithme : suite logique d’instructions. Traduit ensuite en code VBA.

Structure d’un programme :

Sub NomMacro()
    ' déclarations
    ' instructions
End Sub

Variables : Dim nom As Type. Types : String, Integer, Long, Double, Boolean, Date, Variant.

Opérateurs : arithmétiques (+ - * / \ Mod ^), comparaison (= < > <= >= <>), logiques (And Or Not), concaténation (&).

Structures : If...Then...ElseIf...Else...End If ; boucles For...Next, Do While...Loop, Do Until...Loop, Exit For.

Boîtes de dialogue : MsgBox (message, icônes, boutons) et InputBox (saisie).

🔹 Module 4 : VBA dans Excel

Objets principaux : Application, Workbook, Worksheet, Range, Cells.

Lire/écrire : Range("A1").Value = "texte" ; Cells(ligne, colonne).Value.

Boucles sur les lignes : déterminer la dernière ligne avec Cells(Rows.Count, "A").End(xlUp).Row.

Automatisation : calcul de moyennes, génération de décisions (Admis/Ajourné), attribution de mentions (Très Bien, Bien, Assez Bien, Passable, Échec).

Mise en forme : gras, centrage, couleur de fond, bordures, ajustement des colonnes (AutoFit).
