Chapitre 2 — Algèbre de Boole

L'algèbre de Boole, conçue par le mathématicien britannique George Boole au XIXᵉ siècle, est l'outil mathématique fondamental de l'électronique numérique. Elle définit un ensemble de règles de calcul sur des variables qui ne prennent que deux valeurs : 0 (faux) et 1 (vrai). Cette algèbre permet de décrire, d'analyser et de simplifier les fonctions logiques réalisées par les circuits.

1. Variables et opérations booléennes

Définition — Variable booléenne : Une variable booléenne est une grandeur notée A, B, C... qui ne peut prendre que deux valeurs : 0 ou 1. On l'appelle aussi variable logique.

L'algèbre de Boole définit trois opérations fondamentales :

  • Le OU logique (+) : somme logique. A + B = 1 si A=1 ou B=1 (ou les deux).
  • Le ET logique (·) : produit logique. A · B = 1 si A=1 et B=1 simultanément.
  • Le NON (barre ou apostrophe) : complément logique. Ā = 1 si A=0, et inversement.

2. Propriétés et théorèmes de base

Comme l'algèbre classique, l'algèbre de Boole possède des propriétés remarquables :

  • Commutativité : A + B = B + A ; A · B = B · A
  • Associativité : (A + B) + C = A + (B + C) ; (A · B) · C = A · (B · C)
  • Distributivité : A · (B + C) = A·B + A·C ; A + (B · C) = (A+B) · (A+C)
  • Élément neutre : A + 0 = A ; A · 1 = A
  • Absorption : A + 0 = A ; A · 1 = A ; A + 1 = 1 ; A · 0 = 0
  • Idempotence : A + A = A ; A · A = A
  • Complément : A + Ā = 1 ; A · Ā = 0
  • Involution : ¬(¬A) = A
Exemple — Appliquer l'absorption : 
F = A + A·B
  = A·1 + A·B       (car A = A·1)
  = A·(1 + B)       (factorisation)
  = A·1             (car 1 + B = 1)
  = A
L'expression se simplifie en simplement F = A.

3. Théorèmes de De Morgan

Les théorèmes de De Morgan sont fondamentaux pour transformer et simplifier les expressions logiques. Ils permettent notamment de passer d'une forme "somme de produits" à une "produit de sommes", et de réaliser n'importe quelle fonction avec uniquement des portes NAND ou NOR.

Théorèmes de De Morgan :
  • Premier théorème : ¬(A · B) = Ā + B̄ (le NON d'un ET = OU des NON)
  • Deuxième théorème : ¬(A + B) = Ā · B̄ (le NON d'un OU = ET des NON)
Généralisation à n variables : ¬(A · B · C · ...) = Ā + B̄ + C̄ + ...
Exemple — Appliquer De Morgan :
Soit F = ¬(A · B · C). D'après De Morgan :
F = Ā + B̄ + C̄
Cette transformation est essentielle pour le câblage avec portes NAND.

4. Formes canoniques

Toute fonction logique peut être écrite sous deux formes canoniques :

4.1 Première forme canonique (somme de mintermes)

On exprime la fonction comme une somme (OU) de produits (ET) appelés mintermes. Chaque minterme correspond à une combinaison des variables pour laquelle la fonction vaut 1.

Pour F(A,B,C) = 1 si et seulement si exactement deux variables valent 1, on obtient :

F = Ā·B·C + A·B̄·C + A·B·C̄
  = Σm(3, 5, 6)

4.2 Deuxième forme canonique (produit de maxtermes)

On exprime la fonction comme un produit (ET) de sommes (OU) appelés maxtermes. Chaque maxterm correspond à une combinaison pour laquelle la fonction vaut 0.

Remarque : Les deux formes sont équivalentes et représentent la même fonction. Le choix dépend du contexte (synthèse avec portes AND-OR ou OR-AND).

5. Simplification algébrique

La simplification algébrique consiste à appliquer les théorèmes pour réduire l'expression à sa forme minimale, ce qui se traduit par un circuit moins coûteux (moins de portes, moins d'interconnexions).

Exemple — Simplifier : 
F = A·B + A·B·C + Ā·B
  = A·B·(1 + C) + Ā·B     (factorisation)
  = A·B + Ā·B             (car 1 + C = 1)
  = B·(A + Ā)             (factorisation)
  = B·1                   (A + Ā = 1)
  = B
Résultat : F = B — bien plus simple !

6. Tableaux de Karnaugh

La méthode algébrique devient rapidement fastidieuse pour les fonctions à 3, 4 voire 5 variables. Le tableau de Karnaugh offre une méthode graphique de simplification basée sur le regroupement de cases adjacentes.

6.1 Construction

Pour une fonction à 2 variables (A, B), on construit un tableau 2×2. Pour 3 variables, 2×4. Pour 4 variables, 4×4. L'ordre des colonnes et lignes suit le code Gray afin que deux cases adjacentes ne diffèrent que d'une seule variable.

6.2 Méthode de regroupement

  • Identifier les cases contenant un 1.
  • Former des groupes de 1, 2, 4, 8 ou 16 cases adjacentes (puissances de 2).
  • Les groupes peuvent chevaucher la frontière (bouclage cyclique).
  • Chaque groupe donne un terme : on conserve les variables qui ne changent pas.
Exemple — F(A,B,C) = Σm(1, 3, 5, 7) 
        BC
       00  01  11  10
   A0   0   1   1   0
   A1   0   1   1   0
Toute la colonne "1" centrale forme un bloc de 4 cases : seule la variable C est constante (=1).
F = C
Remarque — Indifférences : Les conditions "don't care" (X) sont notées pour les combinaisons impossibles ou sans importance. Elles peuvent être incluses dans un groupe pour atteindre une taille supérieure et donc une simplification plus poussée.

6.3 Méthode pratique : étapes de simplification par Karnaugh

Pour utiliser efficacement un tableau de Karnaugh, il convient de suivre une démarche rigoureuse :

  1. Identifier les variables de la fonction et le nombre de cases (2ⁿ pour n variables).
  2. Reporter les 1 dans les cases correspondant aux mintermes de la fonction.
  3. Marquer les X (don't care) si certaines combinaisons sont impossibles.
  4. Former les plus grands groupes possibles de 1 adjacents (1, 2, 4, 8, 16...). Plus le groupe est grand, plus le terme final est simple.
  5. Toujours inclure les X dans un groupe si cela permet d'agrandir ce dernier.
  6. Pour chaque groupe, identifier les variables qui ne changent pas : elles constituent le terme.
  7. Combiner tous les termes par OU pour obtenir l'expression simplifiée.
Remarque — Adjacence dans Karnaugh : Deux cases sont adjacentes si elles diffèrent d'exactement une variable. Cela inclut les cases situées sur les bords opposés du tableau (bouclage cyclique) ainsi que les quatre coins d'un tableau 4×4, qui forment un groupe de 4 cases valides.

La méthode de Karnaugh reste limitée à 4 voire 5 variables au-delà desquelles la lecture devient fastidieuse. Pour des fonctions plus complexes, on recourt à la méthode algorithmique de Quine-McCluskey, qui automatise la simplification par ordinateur.

Exercice 1 : Démontrer que (A + B)·(A + C) = A + B·C (distributivité du OU sur le ET).
Exercice 2 : Simplifier algébriquement F = A·B + Ā·C + B·C et donner le résultat minimal. (Indice : utiliser le théorème de consensus.)

En résumé — L'algèbre de Boole fournit les outils mathématiques pour manipuler les fonctions logiques. Les théorèmes de De Morgan, les formes canoniques et les tableaux de Karnaugh sont les méthodes essentielles pour passer d'une spécification à un circuit optimal. Le chapitre suivant aborde les portes logiques qui constituent les briques physiques de mise en œuvre de ces fonctions.
