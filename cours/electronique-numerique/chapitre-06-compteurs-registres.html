Chapitre 6 — Compteurs et registres

Les compteurs et les registres sont les circuits séquentiels les plus utilisés en électronique numérique. Ils trouvent leur place dans les horloges, les minuteries, les processeurs (compteur programme, registres), les convertisseurs, les afficheurs, etc. Ce dernier chapitre présente leur architecture, leurs modes de fonctionnement et introduit les mémoires RAM et ROM.

Définition — Compteur : Un compteur est un circuit séquentiel qui parcourt une séquence déterminée d'états binaires à chaque impulsion d'horloge. Un compteur à n bascules peut compter jusqu'à 2ⁿ états (modulo 2ⁿ). On distingue les compteurs progressifs (incrément), déprogressifs (décrément) et réversibles (les deux selon une commande).

1. Compteurs asynchrones

Dans un compteur asynchrone (ou "à retenue propagée"), la sortie d'une bascule pilote l'horloge de la suivante. La transition se propage de proche en proche, comme dans un additionneur ripple-carry.

Exemple — Compteur asynchrone modulo 8 :
Trois bascules JK configurées en toggle (J = K = 1) sont cascadées : la sortie Q₀ pilote CLK₁, Q₁ pilote CLK₂. Sur front descendant de l'horloge, Q₀ bascule, et chaque Qᵢ bascule quand Qᵢ₋₁ descend. 
CLK   ↓   ↓   ↓   ↓   ↓   ↓   ↓   ↓
Q₀    0   1   0   1   0   1   0   1   0
Q₁    0   0   1   1   0   0   1   1   0
Q₂    0   0   0   0   1   1   1   1   0
État  000 001 010 011 100 101 110 111 000
Le compteur parcourt les 8 états de 000 à 111, puis revient à 000.
Remarque — Inconvénient : La propagation de la retenue provoque un retard cumulé : à chaque étage, le signal prend plus de temps à se stabiliser. Au-delà de quelques bits, la sortie peut momentanément afficher des valeurs fausses (aléas). C'est pourquoi on préfère souvent les compteurs synchrones.

2. Compteurs synchrones

Dans un compteur synchrone, toutes les bascules reçoivent le même signal d'horloge. Une logique combinatoire détermine, en fonction de l'état courant, quelles bascules doivent basculer. Tous les changements sont simultanés, d'où un temps de propagation indépendant du nombre de bits.

Conception d'un compteur synchrone 3 bits en code binaire naturel :

  1. Lister les transitions (table d'excitation).
  2. Pour chaque bascule, exprimer les entrées J et K en fonction de l'état présent.
  3. Simplifier par Karnaugh.
  4. Câbler.

On obtient typiquement : J₀ = K₀ = 1 (bascule toujours), J₁ = K₁ = Q₀, J₂ = K₂ = Q₀·Q₁. La logique est un peu plus complexe mais la vitesse bien supérieure.

Exemples de compteurs synchrones intégrés : 74LS161 (4 bits, chargement parallèle, enable), 74LS160 (BCD 0 à 9), 74LS190 (réversible BCD).

3. Compteurs modulo N

Un compteur modulo N parcourt N états distincts puis revient à l'état initial. Avec n bascules, on peut réaliser tout modulo N tel que N ≤ 2ⁿ. La technique consiste à détecter l'état N (ou N−1) et à forcer la remise à zéro.

Exemple — Compteur modulo 6 :
Trois bascules suffisent (2³ = 8 ≥ 6). On déclenche un reset quand le compteur atteint 110 (6) grâce à une porte NAND : RESET = ¬(Q₂ · Q₁). La séquence est : 000 → 001 → 010 → 011 → 100 → 101 → 000.
Pour un compteur synchrone, on peut aussi utiliser une entrée LOAD parallèle qui recharge la valeur initiale à l'état désiré.

Les compteurs modulo N trouvent des applications dans les horloges (modulo 60 pour les secondes/minutes, modulo 24 pour les heures), les minuteries, les diviseurs de fréquence, les compteurs d'événements, etc.

4. Registres à décalage

Un registre est un ensemble de bascules D placées en parallèle, qui permet de stocker un mot binaire de n bits. Un registre à décalage (shift register) interconnecte les bascules de façon à propager l'information bit par bit à chaque coup d'horloge.

Il existe quatre modes de fonctionnement principaux :

  • SISO (Serial In - Serial Out) : entrée et sortie série. Utilisé comme ligne à retard ou mémoire tampon.
  • SIPO (Serial In - Parallel Out) : entrée série, sortie parallèle. Conversion série → parallèle.
  • PISO (Parallel In - Serial Out) : conversion parallèle → série.
  • PIPO (Parallel In - Parallel Out) : registre de stockage simple.
Exemple — Registre à décalage 4 bits SIPO :
Sur chaque front montant d'horloge, le bit d'entrée série est recopié dans Q₀, et chaque Qᵢ prend la valeur de Qᵢ₋₁. Au bout de 4 coups d'horloge, le mot de 4 bits est entièrement disponible en parallèle. 
Entrée série : 1 0 1 1
CLK 0 : Q = 0000
CLK 1 : Q = 0001
CLK 2 : Q = 0010
CLK 3 : Q = 0101
CLK 4 : Q = 1011 ← mot reçu

En refermant la sortie d'un registre à décalage sur son entrée, on obtient un compteur en anneau (un seul 1 circule) ou un compteur Johnson (en injectant le complément, on obtient 2N états avec N bascules). Ces structures sont utilisées pour générer des séquences pseudo-aléatoires, des chenillards, du codage Manchester, etc.

Définition — Registre universel : Un registre universel combine les quatre modes (SISO, SIPO, PISO, PIPO) avec des entrées de sélection de mode et un sens de décalage programmable (gauche/droite). Le 74LS194 est un registre universel 4 bits très répandu.

5. Mémoires RAM et ROM

5.1 Mémoire ROM (Read-Only Memory)

La ROM est une mémoire morte : son contenu est fixé à la fabrication (ou par programmation électrique une fois pour toutes en PROM, EPROM, EEPROM). Elle conserve les données sans alimentation (mémoire non volatile). On l'utilise pour stocker le firmware, les tables de constantes, les fonctions logiques combinatoires complexes.

Une ROM de 2ⁿ mots de m bits se comporte comme un grand décodeur suivi d'un réseau de connexions fixes : elle réalise n'importe quelle fonction combinatoire de n variables à m sorties. Idéale pour implémenter une UAL ou des tables de sinus.

5.2 Mémoire RAM (Random Access Memory)

La RAM est une mémoire vive accessible en lecture et en écriture, mais volatile (perte des données à l'extinction). On distingue :

  • SRAM (Static RAM) : chaque cellule est une bascule (typiquement 6 transistors). Très rapide mais encombrante. Utilisée pour les caches de processeurs.
  • DRAM (Dynamic RAM) : chaque cellule est un transistor + un condensateur. Le condensateur se décharge progressivement, d'où la nécessité d'un raffraîchissement périodique. Très dense et bon marché, c'est la mémoire principale des ordinateurs (barrettes DIMM).
Remarque — Mémoires modernes : Les mémoires flash (NAND, NOR) sont des mémoires non volatiles accessibles en écriture, qui ont remplacé les ROM dans la plupart des appareils modernes (clés USB, SSD, smartphones). Elles reposent sur des transistors à grille flottante.

6. Synthèse et applications

Compteurs et registres sont à la base de tous les systèmes numériques :

  • Processeurs : compteur programme (PC), registres généraux, registre d'instruction, accumulateur.
  • Horloges temps réel : diviseurs de fréquence par 2, 10, 60, etc.
  • Communications série (UART, SPI, I²C) : registres à décalage pour la conversion série ↔ parallèle.
  • Convertisseurs : CAN/CNA à approximations successives utilisant un registre et un compteur.
  • Afficheurs : multiplexage temporel piloté par un compteur.

Conclusion du cours — Au terme de ces six chapitres, vous disposez des fondements complets de l'électronique numérique : systèmes de numération, algèbre de Boole et simplification, portes logiques, logique combinatoire (décodeurs, multiplexeurs, additionneurs, UAL), logique séquentielle (bascules RS, D, JK, T) et enfin compteurs, registres et mémoires. Ces briques de base, assemblées par millions dans les circuits intégrés modernes, sont à l'origine de toute l'informatique d'aujourd'hui.
