Exercice 1 – Architecture & bus système

Énoncé : « Écrivez une note sur l’architecture d’un ordinateur. Qu’est-ce qu’un bus système ? Nommez les différentes unités du bus système. »

Correction

Architecture d’un ordinateur : c’est la structure visible et l’organisation des composants matériels (UC, mémoire, entrées/sorties) interconnectés pour atteindre des objectifs de performance, fonctionnalité et coût. Elle inclut le jeu d’instructions, les modes d’adressage, les registres et les mécanismes d’interruption.

Bus système : ensemble de lignes de transmission (fils) qui interconnectent les unités fonctionnelles (processeur, mémoire, périphériques). Il est divisé en trois sous-ensembles logiques :

  • Bus de données : transporte les données, instructions ou codes entre les unités.
  • Bus d’adresses : véhicule l’adresse mémoire (ou périphérique) ; la communication est unidirectionnelle du processeur vers la mémoire.
  • Bus de commande : signaux de contrôle (lecture/écriture, acquittement, état) qui synchronisent les opérations.
✔ Réponse finale : l’architecture est la structure matérielle, le bus système est l’interconnexion avec ses trois bus (données, adresses, commande).
Exercice 2 – Cycle d’instruction & CPU

Énoncé : « Qu’est-ce qu’un cycle d’instruction ? Décrivez en détail les différentes étapes. Que comprend l’unité centrale de traitement ? »

Correction

Cycle d’instruction : séquence complète des opérations nécessaires pour extraire une instruction de la mémoire, la décoder, exécuter l’opération et stocker le résultat. Il se répète pour chaque instruction du programme.

  • 1. Fetch (chargement) : l’UC place l’adresse de l’instruction dans le MAR, effectue une lecture mémoire et récupère l’instruction dans le registre d’instruction (IR).
  • 2. Décodage : l’UC analyse l’opcode pour déterminer le type d’instruction et active les circuits appropriés.
  • 3. Calcul des adresses des opérandes : l’UC détermine où se trouvent les opérandes (mémoire ou registres).
  • 4. Fetch des opérandes : l’UC lit les opérandes depuis la mémoire ou les registres et les fournit à l’UAL.
  • 5. Exécution : l’UAL réalise l’opération (arithmétique ou logique).
  • 6. Stockage du résultat : le résultat est sauvegardé en mémoire ou dans un registre.

Unité centrale (CPU) : comprend l’unité de contrôle (séquençage et signaux), l’UAL (opérations arithmétiques/logiques) et les registres (mémoire rapide interne).

✔ Cycle en 6 étapes : fetch, decode, adresse opérandes, fetch opérandes, execute, store. CPU = UC + UAL + registres.
Exercice 3 – Communication processeur & périphériques

Énoncé : « Décrivez en détail : a) communication processeur – mémoire ; b) communication processeur – périphériques d’entrée/sortie. »

Correction

a) Processeur ↔ Mémoire
Le processeur place une adresse sur le bus d’adresses (unidirectionnel) pour indiquer la position mémoire. Le bus de commande émet un signal de lecture ou d’écriture. En lecture, la mémoire place les données sur le bus de données (bidirectionnel) vers le processeur. En écriture, le processeur place les données sur le bus de données et la mémoire les enregistre. La synchronisation est assurée par les signaux de contrôle.

b) Processeur ↔ Périphériques (E/S)
La communication utilise également les trois bus. Les périphériques sont connectés via des contrôleurs (interfaces). Le processeur peut accéder aux registres des contrôleurs par des adresses réservées (E/S mappées en mémoire ou E/S dédiées). L’UC utilise le bus de commande pour indiquer une opération d’E/S (lecture/écriture). Les données transitent par le bus de données. Les périphériques peuvent aussi signaler leur état (prêt/busy) via le bus de commande. Les interruptions permettent au périphérique d’attirer l’attention du processeur.

Remarque : Le bus d’adresses est unidirectionnel du processeur vers la mémoire et les E/S ; les bus de données et de commande sont bidirectionnels.
✔ Communication mémoire : adresse + commande + données. Communication E/S : même principe avec gestion des statuts et interruptions.
