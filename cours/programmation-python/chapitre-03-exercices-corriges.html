Exercice 1 – Student Record System (Jour 2)

Énoncé : Écrire un programme Python qui demande à l'utilisateur son nom, son ID, son programme, son niveau et sa GPA, puis affiche ces informations dans un format structuré.

Correction (détaillée)

Objectif : utiliser input() pour la saisie, print() pour l'affichage, et la concaténation/formatage.

Code Python complet :

# Student Record System – Jour 2
# Saisie des informations
nom = input("Entrez votre nom : ")
id_etudiant = input("Entrez votre ID : ")
programme = input("Entrez votre programme : ")
niveau = input("Entrez votre niveau (ex: L1, L2) : ")
gpa = float(input("Entrez votre GPA : "))

# Affichage formaté
print("\n--- FICHE ÉTUDIANT ---")
print("Nom       :", nom)
print("ID        :", id_etudiant)
print("Programme :", programme)
print("Niveau    :", niveau)
print("GPA       :", gpa)
print("Statut    :", "Admis" if gpa >= 2.0 else "Ajourné")
print("------------------------")

Explication :

  • input() récupère une chaîne de caractères.
  • float(input()) convertit la saisie en nombre décimal pour la GPA.
  • L'opérateur ternaire ... if ... else ... permet d'afficher le statut en une ligne.
  • Les sauts de ligne \n améliorent la lisibilité.
✔ Le programme affiche une fiche étudiant complète avec statut (Admis/Ajourné selon GPA ≥ 2.0).
Remarque : Ce code est le socle du projet. Il sera enrichi avec des listes, des fonctions et des classes dans les jours suivants.
