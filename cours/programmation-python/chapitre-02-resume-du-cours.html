🔹 Introduction à la programmation

Programmation : donner des instructions précises et logiques à un ordinateur. Un programme est une suite d'étapes ordonnées.

L'ordinateur est littéral : il exécute exactement ce que vous dites, pas ce que vous voulez dire. Chaque instruction doit être complète et sans ambiguïté.

Langages de bas niveau : assembleur (registres, instructions élémentaires), C (gestion manuelle de la mémoire, compilation).

Python : langage de haut niveau, interprété, généraliste, orienté objet, dynamique, open source.

🔹 Python en pratique

Version : Python 3 (standard actuel, Python 2.7 abandonné).

Usages : web, données, IA, automatisation, fintech (Paystack, Flutterwave, Interswitch, Google, Spotify).

Environnement : Python 3, VS Code (extension Python), GitHub.

Shell (REPL) : environnement interactif (>>>) pour tester des instructions.

🔹 Syntaxe et règles

Commentaires : # commentaire (ligne simple) ou ''' ... ''' (multiligne).

Indentation : 4 espaces par niveau (VS Code le fait automatiquement). Ne pas mélanger tabulations et espaces.

Notation : sensible à la casse (nom ≠ Nom), mots-clés réservés (if, for, class…).

🔹 Projet fil rouge : Student Record System

Un projet construit sur 4 jours pour appliquer les concepts.

  • Jour 2 : Stocker les infos (nom, ID, programme, niveau, GPA), saisie utilisateur, affichage formaté.
  • Jour 3 : Gérer un registre complet, vérifier le statut académique.
  • Jour 4 : Classe Student avec attributs et méthodes.
