Exercice 1 – Transistor NPN

Énoncé : Un transistor NPN a un gain en courant continu \(\beta = 200\). Calculer le courant de base \(I_B\) nécessaire pour commuter une charge résistive de 4 mA.

Correction

Données : \(\beta = 200\), \(I_C = 4 \, mA = 0,004 A\).

En régime actif, \(I_C = \beta \cdot I_B\).

On isole \(I_B = \frac{I_C}{\beta} = \frac{0,004}{200} = 2 \times 10^{-5} A = 20 \, \mu A\).

✔ Le courant de base nécessaire est \(I_B = 20 \, \mu A\).
Exercice 2 – Courant de base

Énoncé : Un transistor NPN a une tension de polarisation de base \(V_B = 10 V\) et une résistance de base \(R_B = 100 k\Omega\). Calculer le courant de base \(I_B\).

Correction

Données : \(V_B = 10 V\), \(R_B = 100 \, k\Omega = 10^5 \Omega\). La tension base-émetteur \(V_{BE}\) est d'environ 0,7 V pour un transistor NPN en actif.

La loi d'Ohm donne : \(I_B = \frac{V_B - V_{BE}}{R_B}\).

Application numérique : \(I_B = \frac{10 - 0,7}{10^5} = \frac{9,3}{10^5} = 9,3 \times 10^{-5} A = 93 \, \mu A\).

✔ Le courant de base vaut \(I_B = 93 \, \mu A\).
Remarque : La tension \(V_{BE}\) est souvent prise égale à 0,7 V pour les transistors en silicium.
