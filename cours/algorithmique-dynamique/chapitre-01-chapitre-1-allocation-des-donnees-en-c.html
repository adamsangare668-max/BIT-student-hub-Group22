📘 Résumé du cours

🔹 1. Variables et mémoire

Une variable est une case mémoire qui stocke une valeur. Ex. int age = 25; réserve un espace et y place 25.

🔹 2. Pointeurs

Un pointeur est une variable qui contient une adresse mémoire.

  • &age → adresse de la variable age
  • *p → valeur stockée à l'adresse pointée par p

Un pointeur est comme une "carte d'adresse" vers une maison.

🔹 3. Passage par adresse

Permet de modifier une variable dans une fonction. Ex. void modifier(int *x) { *x = 100; }

🔹 4. Allocation dynamique

Contourne la taille fixe des tableaux.

  • malloc(n * sizeof(type)) → alloue dans le tas (heap).
  • free(ptr) → libère la mémoire.
À retenir : toujours libérer la mémoire avec free() pour éviter les fuites.

🔹 5. Complexité algorithmique

Mesure l'efficacité d'un algorithme.

  • O(1) : constant (très rapide)
  • O(n) : linéaire (parcours simple)
  • O(n²) : quadratique (lent pour de grandes données)

📝 Exercices corrigés

Exercice 1 – Questions sur les pointeurs

Énoncé : Soit int age = 25; int *p = &age;

  1. Quelle est la valeur de age ?
  2. Que contient p ?
  3. Que représente *p ?
  4. Pourquoi les deux affichages printf("%d", age); et printf("%d", *p); donnent-ils le même résultat ?

Correction

  1. age vaut 25.
  2. p contient l'adresse mémoire de la variable age.
  3. *p représente la valeur pointée, c'est-à-dire la valeur stockée à l'adresse contenue dans p, soit 25.
  4. Les deux affichent 25 car *p déréférence le pointeur pour accéder à la valeur de age.
✔ age = 25 ; p = adresse de age ; *p = 25 ; les deux affichages sont identiques.
Exercice 2 – Chasseur de bugs

Énoncé : Le programme suivant contient des erreurs. Trouvez-les.

#include <stdio.h>
int main()
    int *p;
    *p = 15;
    printf("%d", *p);
    return 0;
}

Correction

Erreurs :

  • Le pointeur p n'est pas initialisé. Il pointe vers une zone mémoire aléatoire (ou NULL).
  • Avant d'utiliser *p, il faut assigner une adresse valide (soit une variable existante, soit un bloc alloué avec malloc()).
  • Il manque les accolades { } autour du corps de main().

Version corrigée :

#include <stdio.h>
int main() {
    int *p;
    int valeur = 15;
    p = &valeur;  // ou p = malloc(sizeof(int));
    *p = 15;
    printf("%d", *p);
    return 0;
}
✔ Le pointeur doit pointer vers une zone mémoire valide avant d'être déréférencé.
Exercice 3 – Allocation avec malloc

Énoncé : Soit int *tab = malloc(5 * sizeof(int));

  1. Combien d'entiers sont créés ?
  2. Où sont-ils stockés ?
  3. Pourquoi utilise-t-on sizeof(int) ?
  4. Que faut-il faire à la fin du programme ?

Correction

  1. 5 entiers sont alloués.
  2. Ils sont stockés dans le tas (heap), une zone mémoire gérée dynamiquement.
  3. sizeof(int) donne la taille en octets d'un entier (généralement 4). Cela permet à malloc() de réserver l'espace exact nécessaire.
  4. Il faut libérer la mémoire avec free(tab); pour éviter les fuites mémoire.
✔ 5 entiers dans le tas ; sizeof(int) pour la taille ; free() pour libérer.
Exercice 4 – Compléter le programme

Énoncé : Compléter le code pour créer dynamiquement une victime et saisir ses informations.

typedef struct {
    char nom[30];
    int age;
    int priorite;
} Victime;

int main() {
    Victime *v;
    // compléter ici
}

Correction

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    char nom[30];
    int age;
    int priorite;
} Victime;

int main() {
    Victime *v = malloc(sizeof(Victime));
    if (v == NULL) { printf("Erreur mémoire\n"); return 1; }

    printf("Nom : "); scanf("%s", v->nom);
    printf("Âge : "); scanf("%d", &v->age);
    printf("Priorité : "); scanf("%d", &v->priorite);

    printf("\n--- Victime ---\n");
    printf("Nom : %s\n", v->nom);
    printf("Âge : %d\n", v->age);
    printf("Priorité : %d\n", v->priorite);

    free(v);
    return 0;
}
✔ Le programme alloue, saisit, affiche et libère la mémoire.
Mini-projet – Registre des victimes (5 victimes)

Énoncé : Écrire un programme capable de gérer 5 victimes sans utiliser un tableau statique. Le programme doit :

  • Définir la structure Victime.
  • Créer dynamiquement les 5 victimes.
  • Demander à l'utilisateur : nom, âge, priorité.
  • Afficher toutes les victimes.
  • Libérer la mémoire.

Correction (solution avec tableau de pointeurs)

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    char nom[30];
    int age;
    int priorite;
} Victime;

int main() {
    Victime *victimes[5];  // tableau de 5 pointeurs
    for (int i = 0; i < 5; i++) {
        victimes[i] = malloc(sizeof(Victime));
        if (victimes[i] == NULL) {
            printf("Erreur mémoire pour la victime %d\n", i+1);
            return 1;
        }
        printf("\n--- Victime %d ---\n", i+1);
        printf("Nom : "); scanf("%s", victimes[i]->nom);
        printf("Âge : "); scanf("%d", &victimes[i]->age);
        printf("Priorité : "); scanf("%d", &victimes[i]->priorite);
    }

    printf("\n=== REGISTRE DES VICTIMES ===\n");
    for (int i = 0; i < 5; i++) {
        printf("%d. %s, %d ans, priorité %d\n",
               i+1, victimes[i]->nom, victimes[i]->age, victimes[i]->priorite);
    }

    for (int i = 0; i < 5; i++) {
        free(victimes[i]);
    }
    return 0;
}
✔ Programme complet : allocation, saisie, affichage, libération.
Remarque : Chaque victime est allouée individuellement dans le tas. Le tableau de pointeurs permet de les gérer sans taille fixe.
