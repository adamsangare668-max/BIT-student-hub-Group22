📘 Résumé du cours

🔹 Chap I : Introduction

Projet : travail temporaire pour créer un produit/service unique. Management de projet : organiser, planifier, exécuter et contrôler.

5 étapes : Initiation → Planification → Exécution → Suivi/Contrôle → Clôture.

Contraintes : coût, délai, qualité, périmètre.

Chef de projet : planifie, coordonne, contrôle, communique.

MS Project : outil de planification, suivi, gestion des ressources, rapports.

Interface : Ruban, zone des tâches, diagramme de Gantt, Timeline.

🔹 Chap II–IV : Démarrage et création

Nouveau projet : modèle vierge ou template. Paramètres : date de début, calendrier (jours/heures).

WBS (Work Breakdown Structure) : décomposition hiérarchique du projet (phases → tâches → sous-tâches).

Tâches : nom, durée, type (Fixed Units, Fixed Duration, Fixed Work).

Ordonnancement : manuel ou automatique. Contraintes : ASAP, MSO, MFO, SNET, FNLT.

🔹 Chap V–VIII : Vues, calendriers, dépendances

Vues : Gantt (planning), Calendrier (mensuel), Réseau de tâches (dépendances), Tables (Entry, Cost, Tracking, Schedule).

Calendriers : Standard, Projet, Ressource. Gestion des exceptions (jours fériés, congés).

Dépendances : FS (Fin→Début), SS (Début→Début), FF (Fin→Fin), SF (Début→Fin).

Avances (Lead) et retards (Lag).

🔹 Chap IX–X : Ressources

Types : Work (humaine), Material (consommable), Cost (dépense).

Affectation : associer une ressource à une tâche. Coût = Travail × Taux.

Surutilisation : détection (rouge dans Resource Usage) et nivellement (répartition automatique).

🔹 Chap XI–XVII : Suivi, rapports, personnalisation

Suivi : % terminé, dates réelles, coûts réels, travail restant.

Baseline : photographie du planning initial (comparaison prévu/réel).

Rapports : export PDF, Excel, tableaux de bord.

Personnalisation : colonnes, couleurs du Gantt, échelle de temps.

Projet maître : regroupe plusieurs sous-projets.

Impression/export : aperçu, orientation, en-têtes/pieds de page.
