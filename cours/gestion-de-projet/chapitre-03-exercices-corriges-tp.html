📝 Exercices corrigés (TP)

TP1 – Création d’un projet simple

Énoncé : Créer un projet “Organisation d’un Séminaire” avec les paramètres suivants :

  • Date de début : 01 Juillet 2026
  • Chef de projet : votre nom
  • Société : nom de votre entreprise
  • Sujet : Formation MS Project
  • Calendrier : Lundi–Vendredi, 08h00–17h00
  • Sauvegarder sous : Seminar_Project_V1.mpp

Correction (procédure détaillée)

  1. Ouvrir MS Project → choisir Blank Project.
  2. Définir la date de début : Onglet Project → Project Information → saisir 01/07/2026 dans Start date.
  3. Informations du projet : Project → Project Information → Advanced Properties : remplir Manager (votre nom), Company (votre entreprise), Subject (“Formation MS Project”).
  4. Vérifier le calendrier : Project → Change Working Time → sélectionner Standard → vérifier que les jours ouvrables sont du lundi au vendredi, de 08:00 à 17:00 (avec pause déjeuner éventuelle).
  5. Sauvegarder : File → Save As → nommer Seminar_Project_V1.mpp.
✔ Projet créé avec les bons paramètres. Le fichier .mpp est prêt pour la suite.
Remarque : La date de début et le calendrier influencent toutes les dates calculées automatiquement.
