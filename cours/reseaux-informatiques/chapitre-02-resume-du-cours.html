📘 Résumé du cours

🔹 I. Généralités

Réseau informatique : infrastructure matérielle, logicielle et protocoles pour l'échange de données, le partage de services et l'interconnexion.

Objectifs : partage de ressources, communication, accès à l'information, fiabilité.

Composants : équipements terminaux, supports de transmission, équipements d'interconnexion, protocoles.

Types : PAN, LAN, MAN (étendue) ; client-serveur, poste à poste (architecture).

🔹 Supports de transmission

Filaires : paire torsadée (Cat 5e à 8, UTP/STP), câble coaxial (RG-58, RG-59, RG-6), fibre optique (monomode SMF, multimode MMF).

Sans fil : ondes radio, micro-ondes, infrarouges.

🔹 Ethernet & topologies

Trame Ethernet : Préambule (7), SFD (1), MAC dest/source (6+6), Type/Longueur (2), Données (46–1500), FCS (4).

Topologies physiques : Bus, Étoile, Anneau. Méthodes d'accès : CSMA/CD (Ethernet), CSMA/CA (Wi-Fi), Token Ring.

Équipements : répéteur, hub, switch, routeur, point d'accès, modem.

🔹 II. Architecture en couches

Modèle OSI (7 couches) : Application, Présentation, Session, Transport, Réseau, Liaison, Physique.

Modèle TCP/IP (4 couches) : Application, Transport (TCP/UDP), Internet (IP), Accès réseau.

Ports : identifiants logiques (0–65535) pour diriger les données vers les applications. Ex. HTTP:80, HTTPS:443, FTP:21, SSH:22.

🔹 III. Adressage IP

IPv4 : 32 bits, notation décimale pointée (ex. 192.168.1.1). Deux parties : Network ID + Host ID.

Classes : A (0–126), B (128–191), C (192–223), D (multicast), E (expérimentale).

Masque : identifie la partie réseau (bits à 1) et la partie hôte (bits à 0). Notation CIDR : /n.

Adresses spéciales : réseau (host bits à 0), broadcast (host bits à 1).

Sous-réseaux (subnetting) : emprunt de bits à la partie hôte pour créer plusieurs réseaux.

Nombre d'hôtes : \(2^n - 2\) où \(n\) = nombre de bits hôtes.
