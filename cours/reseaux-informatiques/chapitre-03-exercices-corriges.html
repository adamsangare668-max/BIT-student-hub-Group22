Exercice 1 – Adresse IP 192.168.10.34/24

Énoncé : Soit l'adresse IP 192.168.10.34/24.

  1. Donner l'adresse réseau.
  2. Donner l'adresse de broadcast.

Correction

1. Adresse réseau

Le masque /24 correspond à 255.255.255.0. L'adresse réseau s'obtient par un ET logique (AND) bit à bit entre l'adresse IP et le masque.

Adresse IP : 192.168.10.34 → 11000000.10101000.00001010.00100010

Masque : 255.255.255.0 → 11111111.11111111.11111111.00000000

ET logique : 11000000.10101000.00001010.00000000 → 192.168.10.0

2. Adresse de broadcast

L'adresse de broadcast a tous les bits de la partie hôte à 1. Avec /24, la partie hôte est le dernier octet (8 bits).

Réseau : 192.168.10.0 → 11000000.10101000.00001010.00000000

Broadcast : mettre tous les bits hôtes à 1 → 11000000.10101000.00001010.11111111 → 192.168.10.255

✔ Réseau : 192.168.10.0 ; Broadcast : 192.168.10.255.
Exercice 2 – Adresse 172.16.0.0/26

Énoncé : Soit l'adresse 172.16.0.0/26.

  1. Combien de bits sont réservés aux hôtes ?
  2. Combien d'hôtes utilisables ce réseau peut-il contenir ?

Correction

1. Bits réservés aux hôtes

Une adresse IPv4 est codée sur 32 bits. Le masque /26 signifie que 26 bits sont utilisés pour la partie réseau.

Bits hôtes = 32 – 26 = 6 bits.

2. Nombre d'hôtes utilisables

Le nombre total d'adresses dans le réseau est \(2^6 = 64\).

Il faut soustraire l'adresse réseau et l'adresse de broadcast (2 adresses spéciales).

Hôtes utilisables = \(2^6 - 2 = 64 - 2 = 62 hôtes\).

✔ Bits hôtes : 6 ; Hôtes utilisables : 62.
Remarque : Les deux adresses non attribuables sont l'adresse réseau (tous les bits hôtes à 0) et l'adresse de broadcast (tous les bits hôtes à 1).
