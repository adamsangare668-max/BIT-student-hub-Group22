1. Définition et types de miroirs sphériques

Définition

Un miroir sphérique est une surface réfléchissante formée par une calotte sphérique. Il peut être obtenu à partir d'une sphère de centre C et de rayon R.

Deux types de miroirs sphériques

  • Miroir concave : la surface réfléchissante est la face interne de la calotte sphérique (face creuse). C'est un miroir convergent.
  • Miroir convexe : la surface réfléchissante est la face externe de la calotte sphérique (face bombée). C'est un miroir divergent.

Figure 2 : Miroir concave et miroir convexe

(Schéma : calotte sphérique, face réfléchissante intérieure/extérieure)

2. Éléments caractéristiques

  • Centre de courbure (C) : centre de la sphère dont est extrait le miroir.
  • Sommet (S) : point central de la calotte sphérique (pôle du miroir).
  • Axe principal (ou axe optique) : droite passant par C et S.
  • Rayon de courbure (R) : distance $R = SC$ (rayon de la sphère).
  • Ouverture du miroir : diamètre de la calotte sphérique.

Figure 1 : Éléments d'un miroir sphérique

(Schéma : C, S, axe principal, rayon R)

Remarque : Le miroir sphérique n'est rigoureusement stigmatique que pour les rayons paraxiaux (proches de l'axe). Pour les rayons éloignés, on observe de l'aberration sphérique.

3. Foyer principal et distance focale

Foyer principal image (F')

Pour un miroir sphérique à stigmatisme approché, le foyer principal image F' est le point de l'axe principal où convergent les rayons incidents parallèles à l'axe après réflexion.

Position du foyer

Le foyer est situé au milieu du segment SC :

$$SF' = \frac{R}{2}$$

Distance focale ($f$)

La distance focale est la distance algébrique entre le sommet S et le foyer F' :

$$f = \overline{SF'}$$

  • Pour un miroir concave : $f > 0$ (foyer réel).
  • Pour un miroir convexe : $f < 0$ (foyer virtuel).

Figure 3 : Foyer d'un miroir concave et d'un miroir convexe

4. Relations de conjugaison

Formule de Descartes (origine au sommet)

La relation de conjugaison pour les miroirs sphériques s'écrit :

$$\frac{1}{\overline{SA'}} + \frac{1}{\overline{SA}} = \frac{1}{f} = \frac{2}{R}$$

où :

  • $\overline{SA}$ : distance algébrique de l'objet au sommet.
  • $\overline{SA'}$ : distance algébrique de l'image au sommet.
  • $f$ : distance focale (positive pour concave, négative pour convexe).

Convention de signes

  • Les distances sont comptées positivement dans le sens de propagation de la lumière (généralement de gauche à droite).
  • Un objet est réel si $\overline{SA} < 0$ (objet à gauche du miroir).
  • Une image est réelle si $\overline{SA'} > 0$ (image à gauche du miroir).

Autre formulation

En posant $p = \overline{SA}$ et $p' = \overline{SA'}$ :

$$\frac{1}{p'} + \frac{1}{p} = \frac{1}{f}$$

Théorème : Pour un miroir sphérique, tout rayon passant par le centre de courbure C se réfléchit sur lui-même.

5. Grandissement

Définition

Le grandissement $\gamma$ est le rapport entre la taille de l'image et celle de l'objet :

$$\gamma = \frac{\overline{A'B'}}{\overline{AB}} = -\frac{\overline{SA'}}{\overline{SA}}$$

Interprétation

  • $\gamma < 0$ : image renversée (par rapport à l'objet).
  • $\gamma > 0$ : image droite.
  • $|\gamma| > 1$ : image plus grande que l'objet.
  • $|\gamma| < 1$ : image plus petite que l'objet.

6. Rayons particuliers (rayons utiles)

Pour construire l'image d'un objet, on utilise trois rayons dont la marche est connue :

Miroir concave

  • Rayon 1 : incident parallèle à l'axe principal → se réfléchit en passant par le foyer F'.
  • Rayon 2 : incident passant par le foyer F' → se réfléchit parallèlement à l'axe.
  • Rayon 3 : incident passant par le centre C → se réfléchit sur lui-même.
  • Rayon 4 : incident passant par le sommet S → se réfléchit symétriquement par rapport à l'axe.

Figure 4 : Rayons utiles pour un miroir concave

Miroir convexe

  • Rayon 1 : incident parallèle à l'axe → se réfléchit en semblant provenir du foyer F'.
  • Rayon 2 : incident dirigé vers le foyer F' → se réfléchit parallèlement à l'axe.
  • Rayon 3 : incident passant par le centre C → se réfléchit sur lui-même.
  • Rayon 4 : incident passant par le sommet S → se réfléchit symétriquement.

Figure 5 : Rayons utiles pour un miroir convexe

7. Construction d'images

Méthode générale

Pour déterminer l'image A'B' d'un objet AB perpendiculaire à l'axe :

  1. Placer l'objet AB (A sur l'axe, B au-dessus).
  2. Tracer deux rayons issus de B en utilisant les rayons utiles.
  3. Le point B' est à l'intersection des rayons réfléchis (ou de leurs prolongements).
  4. A' est la projection de B' sur l'axe optique.

Cas particuliers

  • Objet à l'infini : image au foyer F'.
  • Objet au foyer F : image à l'infini.
  • Objet au centre C : image en C, renversée, même taille.

Remarque : L'image est réelle lorsque les rayons réfléchis se coupent effectivement. Elle est virtuelle lorsque ce sont leurs prolongements qui se coupent.

📌 Exercices corrigés

Voici des exercices types sur les miroirs sphériques avec leurs corrections détaillées.

Exercice 1 — Miroir concave

Énoncé : Un miroir concave a un rayon de courbure $R = 40$ cm. Un objet de hauteur 2 cm est placé à 30 cm du sommet.

1) Calculer la distance focale.

2) Déterminer la position de l'image.

3) Calculer le grandissement et la taille de l'image.

1) Distance focale :

$$f = \frac{R}{2} = \frac{40}{2} = 20\ \text{cm}$$

Miroir concave : $f = +20$ cm.

2) Position de l'image :

Objet réel : $\overline{SA} = -30$ cm.

Formule de conjugaison :

$$\frac{1}{\overline{SA'}} + \frac{1}{\overline{SA}} = \frac{1}{f}$$

$$\frac{1}{\overline{SA'}} - \frac{1}{30} = \frac{1}{20}$$

$$\frac{1}{\overline{SA'}} = \frac{1}{20} + \frac{1}{30} = \frac{3}{60} + \frac{2}{60} = \frac{5}{60} = \frac{1}{12}$$

$$\overline{SA'} = 12\ \text{cm}$$

L'image est réelle (positive), située à 12 cm devant le miroir.

3) Grandissement et taille :

$$\gamma = -\frac{\overline{SA'}}{\overline{SA}} = -\frac{12}{-30} = 0,4$$

$$\overline{A'B'} = \gamma \times \overline{AB} = 0,4 \times 2 = 0,8\ \text{cm}$$

$\gamma > 0$ : image droite. $|\gamma| < 1$ : image plus petite.

$f = 20$ cm ; image à 12 cm ; $\gamma = 0,4$ ; image de 0,8 cm, droite.

Exercice 2 — Miroir convexe

Énoncé : Un miroir convexe a un rayon de courbure $R = -60$ cm. Un objet est placé à 40 cm du sommet.

1) Calculer la distance focale.

2) Déterminer la position de l'image.

3) Calculer le grandissement.

1) Distance focale :

$$f = \frac{R}{2} = \frac{-60}{2} = -30\ \text{cm}$$

2) Position de l'image :

Objet réel : $\overline{SA} = -40$ cm.

$$\frac{1}{\overline{SA'}} - \frac{1}{40} = \frac{1}{-30} = -\frac{1}{30}$$

$$\frac{1}{\overline{SA'}} = -\frac{1}{30} + \frac{1}{40} = \frac{-4 + 3}{120} = -\frac{1}{120}$$

$$\overline{SA'} = -120\ \text{cm}$$

L'image est virtuelle (négative), située à 120 cm derrière le miroir.

3) Grandissement :

$$\gamma = -\frac{\overline{SA'}}{\overline{SA}} = -\frac{-120}{-40} = -3$$

$\gamma < 0$ : image renversée. $|\gamma| > 1$ : image agrandie.

$f = -30$ cm ; image virtuelle à 120 cm ; $\gamma = -3$.

Exercice 3 — Détermination du rayon

Énoncé : Un objet est placé à 25 cm devant un miroir concave. L'image se forme à 50 cm devant le miroir. Calculer le rayon de courbure du miroir.

Données : $\overline{SA} = -25$ cm, $\overline{SA'} = +50$ cm.

$$\frac{1}{f} = \frac{1}{\overline{SA'}} + \frac{1}{\overline{SA}} = \frac{1}{50} + \frac{1}{-25} = \frac{1}{50} - \frac{2}{50} = -\frac{1}{50}$$

$$f = -50\ \text{cm}$$

Ce résultat est incohérent avec un miroir concave (qui a $f > 0$). Il y a une erreur dans les signes ou l'énoncé. Vérification :

$$\frac{1}{\overline{SA'}} + \frac{1}{\overline{SA}} = \frac{1}{50} - \frac{1}{25} = \frac{1}{50} - \frac{2}{50} = -\frac{1}{50}$$

$$R = 2f = -100\ \text{cm}$$

Cela correspondrait à un miroir convexe, pas concave. L'énoncé est donc incohérent ou l'image est virtuelle.

Pas de solution cohérente avec un miroir concave.

Ces exercices couvrent les cas principaux des miroirs sphériques.
