1. Probabilité sur un espace fini

Espace probabilisable

$\Omega = \{\omega_1,\dots,\omega_n\}$ ensemble des résultats. Une probabilité $\mathbb{P}$ est un poids $p_k \ge 0$ avec $\sum p_k=1$. Pour tout événement $A\subset\Omega$ : $$\mathbb{P}(A)=\sum_{\omega_k\in A} p_k.$$

Uniforme : $p_k = 1/\text{Card}(\Omega)$.

Formule de Bayes

Soit $(B_i)$ une partition de $\Omega$. Alors $$\mathbb{P}(B_i \mid A)=\frac{\mathbb{P}(A\mid B_i)\mathbb{P}(B_i)}{\sum_j \mathbb{P}(A\mid B_j)\mathbb{P}(B_j)}.$$

Indépendance

$A,B$ indépendants ssi $\mathbb{P}(A\cap B)=\mathbb{P}(A)\mathbb{P}(B)$. Pour $m$ événements : $\mathbb{P}(\cap_{i\in I} A_i)=\prod_{i\in I}\mathbb{P}(A_i)$ pour tout $I\subset\{1,\dots,m\}$.

2. Variables aléatoires discrètes

Définition et distribution

$X:\Omega\to\mathbb{R}$. Fonction de répartition $F_X(x)=\mathbb{P}(X\le x)$. Fonction de masse $p_X(x)=\mathbb{P}(X=x)$ (cas discret).

Espérance, variance

$$E[\phi(X)] = \sum_x \phi(x)p_X(x) \quad\text{(discret)}$$ $$\mu=E[X],\quad \sigma^2 = E[(X-\mu)^2]=E[X^2]-\mu^2.$$

Couple de variables

Loi jointe $p_{X,Y}(x,y)=\mathbb{P}(X=x,Y=y)$. Lois marginales : $p_X(x)=\sum_y p_{X,Y}(x,y)$. Indépendance : $p_{X,Y}=p_X p_Y$. Covariance : $\sigma_{XY}=E[XY]-\mu_X\mu_Y$.

3. Lois usuelles & TCL

Lois discrètes

  • Bernoulli $\text{Ber}(p)$ : $E=p,\ V=p(1-p)$.
  • Binomiale $\mathcal{B}(n,p)$ : $p_X(k)=C_n^k p^k(1-p)^{n-k}$, $E=np$, $V=np(1-p)$.
  • Géométrique $\text{Geo}(p)$ : $p_X(n)=p(1-p)^{n-1}$, $E=1/p$, $V=(1-p)/p^2$.
  • Poisson $\mathcal{P}(\lambda)$ : $p_X(k)=e^{-\lambda}\lambda^k/k!$, $E=V=\lambda$.
  • Uniforme discrète $\mathcal{U}(n)$ : $p_X(i)=1/n$, $E=(n+1)/2$, $V=(n^2-1)/12$.

Lois continues

  • Uniforme sur $[a,b]$ : $f=1/(b-a)$, $E=(a+b)/2$, $V=(b-a)^2/12$.
  • Exponentielle $\mathcal{E}(\lambda)$ : $f(x)=\lambda e^{-\lambda x}$, $E=1/\lambda$, $V=1/\lambda^2$.
  • Normale $\mathcal{N}(m,\sigma^2)$ : $f(x)=\frac{1}{\sqrt{2\pi\sigma^2}}e^{-\frac{(x-m)^2}{2\sigma^2}}$, $E=m, V=\sigma^2$.
  • Rayleigh : $f(x)=\frac{x}{\sigma^2}e^{-x^2/(2\sigma^2)}$, $E=\sigma\sqrt{\pi/2}$.
  • Nakagami : $f(x)=\frac{2m^m}{\Gamma(m)\omega^m}x^{2m-1}e^{-m x^2/\omega}$.

Théorème central limite

Si $(X_j)$ i.i.d. avec $E[X_1]=\mu$, $V=\sigma^2>0$, alors $$\frac{\sqrt{n}}{\sigma}(\overline{X}_n-\mu) \xrightarrow{\mathcal{L}} \mathcal{N}(0,1).$$

4. Statistique descriptive

Population $\Omega$, individu $\omega$, caractère $X:\Omega\to C$. Modalités : valeurs prises.

Types : qualitatif (nominal, ordinal) / quantitatif (discret, continu).

5. Variable discrète

Effectif $n_i$, fréquence $f_i=n_i/N$, effectif cumulé $N_i=\sum_{j\le i}n_j$, fréquence cumulée $F_i$.

Paramètres de position

  • Mode $M_0$ : valeur de plus grand effectif.
  • Médiane $Me$ : $F(Me^-)<0.5\le F(Me^+)$.
  • Moyenne $\bar{x}=\frac1N\sum n_i x_i=\sum f_i x_i$.

Paramètres de dispersion

  • Étendue $e=x_{\max}-x_{\min}$.
  • Variance $V(X)=\sum f_i(\bar{x}-x_i)^2=\sum f_i x_i^2-\bar{x}^2$.
  • Écart-type $\sigma_X=\sqrt{V(X)}$.

6. Variable continue

On regroupe en classes $[L_k,L_{k+1}[$, amplitude $a_k$, centre $c_k=(L_k+L_{k+1})/2$. Histogramme : aires proportionnelles aux effectifs.

Mode (continue)

Classe modale, $M_o = L_i + \frac{\Delta_1}{\Delta_1+\Delta_2} a_i$, avec $\Delta_1=n_0-n_1$, $\Delta_2=n_0-n_2$.

Médiane

$F(Me)=0.5$. Quartiles $Q_i$ : $F(Q_i)=i/4$.

Moyenne, variance

$\bar{x}=\sum f_i c_i$, $V(X)=\sum f_i c_i^2-\bar{x}^2$, $\sigma_X=\sqrt{V(X)}$.

7. Série bidimensionnelle

Tableau de contingence $n_{ij}$ effectif conjoint. Lois marginales $n_{i\bullet}, n_{\bullet j}$.

Covariance et corrélation

$$\sigma_{XY}=\frac1N\sum_{i,j} n_{ij}(x_i-\bar{x})(y_j-\bar{y}) = \overline{xy}-\bar{x}\bar{y}.$$ $$r_{XY}=\frac{\sigma_{XY}}{\sigma_X\sigma_Y}\in[-1,1].$$

Régression linéaire

Droite $Y=aX+b$ avec $a=\sigma_{XY}/\sigma_X^2$, $b=\bar{y}-a\bar{x}$.

Critère : si $|r|\ge 0.7$, ajustement linéaire acceptable.

Exercice 1 – Chapitre 1

Énoncé : $A,B$ tels que $\mathbb{P}(A)=3/8$, $\mathbb{P}(B)=1/2$, $\mathbb{P}(A\cap B)=1/4$. Calculer $\mathbb{P}(\overline{A}\mid \overline{B})$.

On a $\mathbb{P}(\overline{B})=1-1/2=1/2$. De plus $\mathbb{P}(\overline{A}\cap \overline{B}) = 1-\mathbb{P}(A\cup B)$.

$\mathbb{P}(A\cup B)=\mathbb{P}(A)+\mathbb{P}(B)-\mathbb{P}(A\cap B)=3/8+1/2-1/4=3/8+4/8-2/8=5/8$.

Donc $\mathbb{P}(\overline{A}\cap \overline{B})=1-5/8=3/8$.

$$\mathbb{P}(\overline{A}\mid \overline{B}) = \frac{\mathbb{P}(\overline{A}\cap \overline{B})}{\mathbb{P}(\overline{B})} = \frac{3/8}{1/2} = \frac{3}{4}.$$

Réponse : $3/4$.

Exercice 2 – Indépendance

Énoncé : $A,B$ indépendants, $\mathbb{P}(A)=1/2$, $\mathbb{P}(B)=2/3$. Calculer $\mathbb{P}(\overline{B}\mid A)$.

Indépendance $\Rightarrow \mathbb{P}(\overline{B}\cap A)=\mathbb{P}(\overline{B})\mathbb{P}(A)$.

$\mathbb{P}(\overline{B})=1-2/3=1/3$. Donc $$\mathbb{P}(\overline{B}\mid A)=\frac{\mathbb{P}(\overline{B}\cap A)}{\mathbb{P}(A)}=\mathbb{P}(\overline{B})=1/3.$$

$1/3$.

Exercice 3 – Équivalences indépendance

Énoncé : a) Montrer les équivalences. b) Établir $\mathbb{P}(A\cap B)\mathbb{P}(\overline{A}\cap \overline{B}) = \mathbb{P}(A\cap \overline{B})\mathbb{P}(\overline{A}\cap B)$.

a) $A\perp B \iff \mathbb{P}(A\cap B)=\mathbb{P}(A)\mathbb{P}(B)$. Alors $\mathbb{P}(\overline{A}\cap B)=\mathbb{P}(B)-\mathbb{P}(A\cap B)=\mathbb{P}(B)(1-\mathbb{P}(A))=\mathbb{P}(\overline{A})\mathbb{P}(B)$, donc $\overline{A}\perp B$. De même pour les autres.

b) Posons $p=\mathbb{P}(A), q=\mathbb{P}(B), r=\mathbb{P}(A\cap B)$. L'égalité devient $r(1-p-q+r) = (p-r)(q-r)$. En développant : $r - rp - rq + r^2 = pq - pr - qr + r^2$ $\iff r = pq$. C'est exactement l'indépendance.

Équivalence démontrée.

Exercice 4 – Dés, conditionnelle

Énoncé : On lance deux dés. Probabilité que la somme $\ge 10$ sachant qu'au moins un dé a fait 5.

$B$ : "au moins un 5" ; $A$ : "somme $\ge 10$". $\Omega$ uniforme, $|\Omega|=36$.

$\mathbb{P}(B)=1-\mathbb{P}(\text{pas de 5})=1-(5/6)^2=11/36$.

$A\cap B$ : couples avec un 5 et somme $\ge 10$ : (5,5),(5,6),(6,5) → 3 cas.

Donc $\mathbb{P}(A\mid B)=\frac{3/36}{11/36}=3/11$.

$3/11$.

Exercice 5 (chap.2) – Fonction de répartition

Énoncé : Soit $F$ continue et $h>0$, montrer que $G(x)=\frac1h\int_x^{x+h}F(t)dt$ est une fonction de répartition.

$G$ est continue (primitive), croissante car $F$ l'est. $\lim_{x\to-\infty}G(x)=0$, $\lim_{x\to+\infty}G(x)=1$. Donc $G$ est une f.d.r.

Démontré.

Exercice 6 – Pièce équilibrée, covariance

Énoncé : On lance deux fois. $X$=nombre de piles (0,1,2). On demande loi, covariance avec $Y$ (nombre de faces?). (énoncé complet dans PDF)

Soit $X$ le nombre de Piles sur 2 lancers, $Y$ le nombre de Faces (donc $Y=2-X$). $X\sim \mathcal{B}(2,1/2)$.

$\mathbb{P}(X=k)=C_2^k(1/2)^2$. $E[X]=1, V(X)=1/2$.

$Y=2-X \Rightarrow \text{Cov}(X,Y)=\text{Cov}(X,2-X)=-\text{Var}(X)=-1/2$.

De plus $X$ et $Y$ ne sont pas indépendantes (car $Y$ est fonction de $X$).

Cov = $-1/2$, non indépendantes.

Exercice 7 – Loi jointe, covariance

Énoncé : Tableau $X/Y$ (valeurs 1,2,3 / 1,2,3,4) avec effectifs donnés. Déterminer les lois marginales, indépendance, covariance.

Les effectifs :
X\Y : 1: (0.08,0.04,0.16,0.12) ; 2: (0.04,0.02,0.08,0.06) ; 3: (0.08,0.04,0.16,0.12).

Marginales $X$ : $f_{1\bullet}=0.4$, $f_{2\bullet}=0.2$, $f_{3\bullet}=0.4$.
$Y$ : $f_{\bullet 1}=0.2$, $f_{\bullet 2}=0.1$, $f_{\bullet 3}=0.4$, $f_{\bullet 4}=0.3$.

Exercice 8 – 3 lancers, $X$ et $Y$

Énoncé : 3 lancers ; $X$ = nombre de Faces aux 2 premiers, $Y$=nombre de Piles aux 2 derniers.

Loi conjointe : $X\in\{0,1,2\}$, $Y\in\{0,1,2\}$. Chaque issue équiprobable.

$p_{X,Y}(x,y)$ = probabilité que sur les deux premiers il y ait $x$ Faces et sur les deux derniers $y$ Piles. Indépendance des deux blocs de 2 lancers, donc $p_{X,Y}=p_X p_Y$ avec $p_X\sim \mathcal{B}(2,1/2)$ et $p_Y\sim \mathcal{B}(2,1/2)$.

Donc indépendantes, $\text{Cov}=0$.

Indépendantes, Cov=0.

Exercice 2 – Dés A et B, variable Z

Énoncé : Dé A 1..6, dé B : une face 1, cinq faces 2. $Z$ défini selon $x$ impair, $x=2$ ou 4, $x=6$.

Dé A uniforme, $Y$ (dé B) : $\mathbb{P}(Y=1)=1/6$, $\mathbb{P}(Y=2)=5/6$.

Si $X$ impair (1,3,5) : $Z=Y+1$ → valeurs 2 (si Y=1) avec proba (3/6)*(1/6)=3/36, et 3 (si Y=2) : (3/6)*(5/6)=15/36.

$E[Z^2] = 1*7/36 +4*13/36+9*15/36 = (7+52+135)/36=194/36=97/18$.

$V(Z)=97/18 - (13/6)^2 = 97/18 - 169/36 = (194-169)/36=25/36$, $\sigma=5/6$.

$E=13/6$, $\sigma=5/6$.

Exercice 5 – Densité $f$

Énoncé : $f(x)=x+1$ sur [-1,0[ , $3/2 x^2$ sur [0,1[, 0 sinon. 1) montrer densité, 2) $E,V$, 3) $F$, 4) probas, 5) intervalle de Tchebychev, 6) proba exacte.

1) $\int_{-1}^0 (x+1)dx = [x^2/2+x]_{-1}^0 = 0 - (1/2-1)=1/2$. $\int_0^1 \frac32 x^2 dx = [x^3/2]_0^1=1/2$. Total=1, positive → densité.

2) $E[X]=\int_{-1}^0 x(x+1)dx + \int_0^1 x(3/2 x^2)dx = \int_{-1}^0 (x^2+x)dx + \int_0^1 3/2 x^3 dx$ = $[x^3/3+x^2/2]_{-1}^0 + [3/8 x^4]_0^1$ = $0 - (-1/3+1/2) + 3/8 = -1/6+3/8= (-4+9)/24=5/24$.

3) $F(x)$: pour $x<-1$:0; $-1\le x<0$: $x^2/2+x+1/2$; $0\le x<1$: $1/2 + \int_0^x 3/2 t^2 dt = 1/2 + x^3/2$; $x\ge1$:1.

4) $P(-0.5\le X\le 1)=F(1)-F(-0.5^-)$. $F(-0.5)=(-0.5)^2/2-0.5+0.5 = 0.125$. $F(1)=1$. donc $P=0.875$. $P(X\ge0.5)=1-F(0.5)=1-(1/2+0.125/2)=1-0.5625=0.4375$.

5) Tchebychev : $P(|X-\mu|\ge l) \le V/l^2$. On veut $P(|X-\mu|< l)\ge0.75$ donc $V/l^2\le0.25$ → $l\ge 2\sigma$. $\sigma^2=V=E[X^2]-\mu^2$. $E[X^2]= \int_{-1}^0 x^2(x+1)dx + \int_0^1 x^2(3/2 x^2)dx = \int_{-1}^0 (x^3+x^2)dx + \int_0^1 3/2 x^4 dx$ = $[-1/4+1/3] + 3/10 = 1/12+3/10 = (5+18)/60=23/60$. $V=23/60 - (5/24)^2 = 23/60 - 25/576 = (220.8-25)/576 \approx 195.8/576=0.3399$, $\sigma\approx0.583$. $l=2\sigma\approx1.166$. Intervalle $[\mu-l,\mu+l]\approx[-0.958,1.166]$. On prend $I=[-0.958,1.166]$.

6) $P(X\in I)=F(1.166)-F(-0.958)=1 - F(-0.958)$ (car 1.166>1) ; $F(-0.958)=(-0.958)^2/2-0.958+0.5=0.458-0.958+0.5≈0.0$ ; donc $P\approx1$.

$E=5/24$, $V=23/60-25/576\approx0.3399$, etc.

Exercice 7 – Jeton, covariance

Énoncé : jeton 1/2, $X$ = "faire 1 ou 2" au 1er lancer, $Y$ = "faire 2,3,4" après deux lancers. Lois, espérance, covariance, matrice.

$X$ vaut 1 ou 2 avec proba 1/2. $E[X]=1.5, V=0.25$.

$Y$ est la somme des deux lancers (car 2,3,4). $Y$ prend 2,3,4 avec proba 1/4,1/2,1/4. $E[Y]=3, V=1/2$.

$\text{Cov}(X,Y)=E[XY]-E[X]E[Y]$. $XY = X(X_1+X_2)=X^2+X_1X_2$ avec $X_1$ premier lancer, $X_2$ second. $E[X^2]=(1+4)/2=2.5$, $E[X_1X_2]=E[X_1]E[X_2]=1.5^2=2.25$ → $E[XY]=4.75$; $\text{Cov}=4.75-4.5=0.25$.

Matrice $\Sigma = \begin{pmatrix}0.25&0.25\\0.25&0.5\end{pmatrix}$.

$U_1=2X-Y$ : $V(U_1)=4V(X)+V(Y)-4\text{Cov}=1+0.5-1=0.5$.

$U_2=X+2Y$ : $V(U_2)=0.25+4*0.5+4*0.25=0.25+2+1=3.25$.

Matrice donnée, variances 0.5 et 3.25.

Exercice 8 – Couple $(X,Y)$, densité

Énoncé : $f(x,y)=k(x+y)$ sur $[0,1]^2$. 1) $k$, 2) dépendance, 3) $P(X+Y<1)$, 4) fonction de répartition $F_x$.

1) $\int_0^1\int_0^1 k(x+y)dxdy = k(1/2+1/2)=k=1$. Donc $k=1$.

2) $f_X(x)=\int_0^1 (x+y)dy = x+1/2$, $f_Y(y)=y+1/2$. $f_X f_Y = (x+1/2)(y+1/2) \ne x+y$ → dépendantes.

3) $P(X+Y<1)=\int_{x=0}^{1}\int_{y=0}^{1-x} (x+y) dy dx = \int_0^1 [xy+y^2/2]_0^{1-x} dx = \int_0^1 [x(1-x)+(1-x)^2/2] dx$ = $\int_0^1 (x-x^2 + (1-2x+x^2)/2) dx = \int_0^1 (1/2 - x/2 + 0x^2) dx = [x/2 - x^2/4]_0^1 = 1/2-1/4=1/4$.

4) $F_X(x)=0$ si $x<0$; pour $0\le x\le1$, $F_X(x)=\int_0^x (t+1/2)dt = x^2/2+x/2$; pour $x>1$, $F_X=1$.

$k=1$, dépendantes, $P=1/4$, $F_X$ ci-dessus.

Énoncé : calculs de sommes avec moyenne.

1) $S=\sum_{i=1}^n (a x_i - a\bar{x}+a)=a\sum x_i - a n\bar{x}+ a n = a n\bar{x}-a n\bar{x}+a n = a n = 2$ (car $na=2$).

2) $A=\sum_{i=1}^n (y_i - n\bar{y}) = n\bar{y} - n^2\bar{y}$.

3) $f(a)=\sum (y_i-a)^2$ minimale en $a=\bar{y}$.

$S=2$, $A=n\bar{y}(1-n)$, $a=\bar{y}$.

Statistiques – Exercice 4 (écoles)

Énoncé : 1000 écoles, nombre d'élèves malades (1 à 6) effectifs 50,150,350,300,100,50.

$N=1000$. $X$ valeurs 1..6. $n_1=50$... $f_1=0.05$, etc.

Moyenne $\bar{x} = (50*1+150*2+350*3+300*4+100*5+50*6)/1000 = (50+300+1050+1200+500+300)/1000=3400/1000=3.4$.

Mode = 3 (fréq max 350).

Médiane : $F(2)=0.2$, $F(3)=0.55$ donc $Me=3$.

$Q_1$ : $F(2)=0.2<0.25$ et $F(3)=0.55$ → $Q_1=3$. $Q_3$ : $F(4)=0.85$ → $Q_3=4$.

Variance : $\sum f_i x_i^2 - \bar{x}^2$. $\sum f_i x_i^2 = (50*1+150*4+350*9+300*16+100*25+50*36)/1000 = (50+600+3150+4800+2500+1800)/1000=12900/1000=12.9$. $V=12.9-3.4^2=12.9-11.56=1.34$, $\sigma\approx1.157$.

Écart moyen : $\sum f_i |x_i-\bar{x}| = 0.05*2.4+0.15*1.4+0.35*0.4+0.3*0.6+0.1*1.6+0.05*2.6 = 0.12+0.21+0.14+0.18+0.16+0.13=0.94$.

Coeff var = $\sigma/\bar{x}=1.157/3.4=0.340$.

Moy=3.4, mode=3, médiane=3, Q1=3, Q3=4, V=1.34, écart-moy=0.94, CV=0.34.

Statistiques – Exercice 6 (ville)

Énoncé : population tous les 5 ans. Changement $z=\ln(y)$, régression, estimation.

Les calculs de régression se font sur $(x,z)$. On calcule $\bar{x},\bar{z}, \sigma_x^2, \sigma_{xz}$. Droite $z=ax+b$ avec $a=\sigma_{xz}/\sigma_x^2$, $b=\bar{z}-a\bar{x}$. Puis $y=e^{ax+b}$.

Pour $y=700$, $z=\ln700\approx6.55$, on résout $6.55=ax+b$ pour trouver $x$. Extrapolation 5 ans après : $x=55$, on calcule $y=e^{55a+b}$.

Méthode de régression exponentielle.
