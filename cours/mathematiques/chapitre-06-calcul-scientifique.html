1. Introduction à Python scientifique

Qu'est-ce que le calcul scientifique ?

Le calcul scientifique est l'utilisation d'outils numériques, d'algorithmes et de programmation pour résoudre des problèmes mathématiques, scientifiques et d'ingénierie. Il combine :

  • Mathématiques (modèles, équations, statistiques)
  • Algorithmes (méthodes numériques)
  • Programmation (implémentation)

Écosystème Python

  • NumPy : tableaux, vecteurs, matrices, opérations vectorisées
  • SciPy : algorithmes scientifiques (optimisation, intégration, algèbre linéaire)
  • Pandas : manipulation de données tabulaires (CSV, Excel)
  • Matplotlib : visualisation scientifique
  • Jupyter : cahiers interactifs

NumPy : vecteurs, matrices, fonctions

Un tableau NumPy permet d'effectuer des opérations élément par élément sans boucles explicites.

import numpy as np
x = np.array([1, 2, 3, 4, 5])
print(x + 2)          # [3 4 5 6 7]
print(x * x)          # [ 1  4  9 16 25]
print(np.sin(x))      # fonctions mathématiques vectorisées

Matrices et opérations

A = np.array([[2, 1], [3, 4]])
b = np.array([5, 6])
print(A @ b)          # produit matrice-vecteur
print(np.linalg.det(A))
print(np.linalg.solve(A, b))

Visualisation avec Matplotlib

import matplotlib.pyplot as plt
x = np.linspace(0, 10, 100)
y = x**2
plt.plot(x, y)
plt.xlabel("x"); plt.ylabel("y = x²")
plt.grid(True); plt.show()

3. Méthodes numériques

Erreurs numériques

  • Erreur d'arrondi : précision finie de l'ordinateur
  • Erreur de troncature : approximation d'un processus infini

Résolution d'équations non linéaires

On cherche $x$ tel que $f(x)=0$.

Méthode de la bissection

Si $f$ continue sur $[a,b]$ et $f(a)f(b)<0$, il existe une racine. On divise l'intervalle par 2 itérativement.

def bisection(f, a, b, tol=1e-6):
    if f(a)*f(b) >= 0: raise ValueError
    while (b-a)/2 > tol:
        m = (a+b)/2
        if f(m) == 0: return m
        elif f(a)*f(m) < 0: b = m
        else: a = m
    return (a+b)/2

Méthode de Newton-Raphson

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$

Plus rapide mais nécessite la dérivée et un bon point initial.

Systèmes linéaires

Résoudre $Ax=b$. Méthodes :

  • Élimination de Gauss (pivot)
  • Jacobi : $x^{(k+1)} = (b - (A-D)x^{(k)})/D$
  • Gauss-Seidel : utilise les valeurs les plus récentes

4. Interpolation, intégration, ODE

Interpolation linéaire

$$y = y_1 + \frac{x-x_1}{x_2-x_1}(y_2-y_1)$$

Dérivation numérique

Différence centrale : $f'(x) \approx \frac{f(x+h)-f(x-h)}{2h}$

Intégration numérique

  • Rectangle : $\int_a^b f(x)dx \approx h\sum f(x_k)$
  • Trapèzes : $\int_a^b f(x)dx \approx \frac{h}{2}[f(x_0)+2\sum_{k=1}^{n-1} f(x_k)+f(x_n)]$
  • Simpson : $\int_a^b f(x)dx \approx \frac{h}{3}[f(x_0)+4\sum_{\text{impair}}f(x_k)+2\sum_{\text{pair}}f(x_k)+f(x_n)]$

Équations différentielles ordinaires

Problème : $y' = f(t,y), y(t_0)=y_0$.

  • Euler : $y_{n+1} = y_n + h f(t_n,y_n)$
  • RK4 : $y_{n+1} = y_n + \frac{h}{6}(k_1+2k_2+2k_3+k_4)$

Chapitre 3 — Méthodes numériques

Exercice 1 — Bissection

Énoncé : Approcher la racine de $f(x)=x^3-x-2$ sur $[1,2]$.

def f(x): return x**3 - x - 2
def bisection(f, a, b, tol=1e-6):
    if f(a)*f(b) >= 0: raise ValueError
    while (b-a)/2 > tol:
        m = (a+b)/2
        if f(m) == 0: return m
        elif f(a)*f(m) < 0: b = m
        else: a = m
    return (a+b)/2
racine = bisection(f, 1, 2)
print(racine)  # ~1.521379709
Racine ≈ 1.52138.

Exercice 2 — Newton-Raphson

Énoncé : Appliquer Newton à $f(x)=x^2-5$.

def f(x): return x**2 - 5
def df(x): return 2*x
def newton(f, df, x0, tol=1e-6):
    x = x0
    while True:
        x_new = x - f(x)/df(x)
        if abs(x_new - x) < tol: return x_new
        x = x_new
racine = newton(f, df, 2)
print(racine)  # ~2.2360679
$\sqrt{5} \approx 2.23607$.

Chapitre 4 — Interpolation, intégration, ODE

Exercice 1 — Interpolation linéaire

Énoncé : Interpoler entre (2,10) et (5,25) en $x=3$.

def interpol(x, x1, y1, x2, y2):
    return y1 + (x-x1)*(y2-y1)/(x2-x1)
val = interpol(3, 2, 10, 5, 25)
print(val)  # 15.0
15.0.

Exercice 2 — Dérivée numérique

Énoncé : $f(x)=\sin x$, approximer $f'(1)$.

def deriv(f, x, h=1e-5):
    return (f(x+h)-f(x-h))/(2*h)
f = np.sin
print(deriv(f, 1))  # ~0.5403023 (cos(1))
$\cos(1) \approx 0.5403$.

Exercice 3 — Intégration trapèzes

Énoncé : $\int_0^1 x^2 dx$ avec la méthode des trapèzes.

def trapez(f, a, b, n):
    h = (b-a)/n
    s = 0.5*(f(a)+f(b))
    for k in range(1,n):
        s += f(a+k*h)
    return h*s
f = lambda x: x**2
print(trapez(f, 0, 1, 100))  # ~0.33335
≈ 1/3.

Exercice 4 — Euler

Énoncé : $y'=0.5y$, $y(0)=10$, $h=0.1$, 20 pas.

def euler(f, t0, y0, h, n):
    t, y = t0, y0
    for k in range(n):
        y = y + h*f(t,y)
        t = t + h
    return t, y
f = lambda t,y: 0.5*y
t, y = euler(f, 0, 10, 0.1, 20)
print(y)  # ~27.18 (proche de 10*e^(1)=27.18)
≈ 27.18.

Exercice 5 — Logistique

Énoncé : Simuler $\frac{dU}{dt}=rU(1-U/K)$ avec $r=0.3, K=1000, U(0)=50$.

def logistique(t, U):
    r, K = 0.3, 1000
    return r*U*(1 - U/K)
t0, U0, h, n = 0, 50, 0.5, 100
t_vals, U_vals = [], []
t, U = t0, U0
for k in range(n):
    t_vals.append(t); U_vals.append(U)
    U = U + h*logistique(t,U)
    t = t + h
plt.plot(t_vals, U_vals)
plt.xlabel("Temps"); plt.ylabel("Utilisateurs")
plt.title("Croissance logistique")
plt.grid(True); plt.show()
Courbe en S typique de la logistique.
