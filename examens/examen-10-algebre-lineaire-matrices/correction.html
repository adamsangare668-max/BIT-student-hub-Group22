📋 Énoncé résumé

Le sujet porte sur les matrices et déterminants :

  1. calcul du déterminant de A = [[2, 1, 0], [1, 3, 1], [0, 1, 2]] ;
  2. inversion de A par la méthode des cofacteurs ;
  3. résolution du système A·X = b avec b = (1, 2, 3) par la règle de Cramer ;
  4. diagonalisation de B = [[2, 1], [1, 2]].
Définition — Déterminant. Le déterminant d'une matrice carrée A d'ordre n est un scalaire noté det(A) qui mesure le volume orienté du parallélépipède formé par les vecteurs colonnes de A. Il est nul si et seulement si A n'est pas inversible. Pour une matrice 3×3, on utilise la règle de Sarrus ou le développement par cofacteurs.

💡 Méthodologie

  1. Déterminant 3×3 : règle de Sarrus ou développement par cofacteurs.
  2. Inversion : A−1 = (1/det A) · tcom(A), où com(A) est la comatrice.
  3. Règle de Cramer : xi = det(Ai)/det(A), où Ai est A avec la i-ème colonne remplacée par b.
  4. Diagonalisation : calculer le polynôme caractéristique, les valeurs propres, les sous-espaces propres.

✅ Solution détaillée

Question 1 — Déterminant de A

Par développement selon la première ligne :

det(A) = 2·det[[3,1],[1,2]] − 1·det[[1,1],[0,2]] + 0
       = 2·(6−1) − 1·(2−0) + 0
       = 10 − 2 = 8

det(A) ≠ 0, donc A est inversible.

Question 2 — Inversion par cofacteurs

On calcule la comatrice. Les cofacteurs :

C11 = +det[[3,1],[1,2]] = 5    C12 = −det[[1,1],[0,2]] = −2    C13 = +det[[1,3],[0,1]] = 1
C21 = −det[[1,0],[1,2]] = −2    C22 = +det[[2,0],[0,2]] = 4     C23 = −det[[2,1],[0,1]] = −2
C31 = +det[[1,0],[3,1]] = 1     C32 = −det[[2,0],[1,1]] = −2    C33 = +det[[2,1],[1,3]] = 5

D'où la transposée (comatrice) :

A−1 = (1/8) · [[5, −2, 1],
                  [−2, 4, −2],
                  [1, −2, 5]]

Vérification : A · A−1 = I3.

Question 3 — Règle de Cramer

Avec b = (1, 2, 3)T, on remplace chaque colonne :

A1 = [[1,1,0],[2,3,1],[3,1,2]] ⇒ det(A1) = 1·5 − 1·1 + 0 = 4   ⇒ x1 = 4/8 = 1/2
A2 = [[2,1,0],[1,2,1],[0,3,2]] ⇒ det(A2) = 2·1 − 1·2 + 0 = 0    ⇒ x2 = 0/8 = 0
A3 = [[2,1,1],[1,3,2],[0,1,3]] ⇒ det(A3) = 2·7 − 1·3 + 1·1 = 12  ⇒ x3 = 12/8 = 3/2

La solution est X = (1/2, 0, 3/2). Vérification : 2·(1/2) + 1·0 + 0 = 1 ✓, etc.

Question 4 — Diagonalisation de B = [[2, 1], [1, 2]]

Polynôme caractéristique :

χB(λ) = det(B − λI) = (2−λ)2 − 1 = λ2 − 4λ + 3 = (λ−1)(λ−3)

Valeurs propres : λ1 = 1, λ2 = 3. Vecteurs propres associés :

  • Pour λ1 = 1 : (B − I)v = 0 ⇒ v = (1, −1).
  • Pour λ2 = 3 : (B − 3I)v = 0 ⇒ v = (1, 1).

La matrice de passage P = [[1, 1], [−1, 1]] diagonalise B :

P−1BP = [[1, 0], [0, 3]] = D

B est donc diagonalisable, avec spectre {1, 3}.

Exemple appliqué. La diagonalisation simplifie le calcul des puissances : Bn = P·Dn·P−1. Par exemple, B10 = P·diag(1, 59049)·P−1 se calcule en quelques opérations.
Exercice d'application. Reprenez la méthodologie ci-dessus avec des valeurs numériques différentes (par exemple un autre jeu de paramètres) et vérifiez que vous arrivez au bon résultat. Puis essayez de refaire l'exercice sans regarder la solution : c'est la meilleure façon de fixer durablement la méthode.

📝 Notes importantes

  • Déterminant et inversibilité : A inversible ⇔ det(A) ≠ 0.
  • Multiplicativité : det(AB) = det(A)·det(B).
  • Cofacteurs : bien respecter le signe (−1)i+j.
  • Diagonalisation : une matrice est diagonalisable si la somme des dimensions des sous-espaces propres égale n.

📚 Pour aller plus loin

  • Le théorème spectral : toute matrice symétrique réelle est diagonalisable dans une base orthonormée.
  • La Jordanisation généralise la diagonalisation aux matrices non diagonalisables.
  • Les valeurs singulières (SVD) étendent la diagonalisation aux matrices rectangulaires.
  • Les matrices apparaissent partout : systèmes d'équations, graphes (matrice d'adjacence), mécanique quantique, machine learning.
