📋 Énoncé résumé

Le TP C demande de gérer un carnet d'adresses en C avec :

  1. une structure Contact (nom, prénom, téléphone, email) ;
  2. une fonction d'ajout de contact dans un tableau dynamique ;
  3. une fonction de recherche par nom ;
  4. la sauvegarde dans un fichier texte et le chargement au démarrage ;
  5. un menu interactif en ligne de commande.
Définition — Structure. Une structure C (struct) est un type composé regroupant plusieurs champs de types potentiellement différents sous un même nom. Elle permet de manipuler des enregistrements logiques (Contact, Étudiant, Point, etc.). On accède aux champs par l'opérateur . (sur une variable) ou -> (sur un pointeur).

💡 Méthodologie

  1. Définir la structure avec typedef pour simplifier l'écriture.
  2. Allouer dynamiquement le tableau de contacts avec malloc + realloc.
  3. Manipuler les chaînes avec strcpy, strcmp, strncpy (sécurisée).
  4. Lire/écrire dans un fichier avec fopen, fprintf, fscanf, fgets.
  5. Fermer systématiquement les fichiers et libérer la mémoire.

✅ Solution détaillée

Déclaration de la structure

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define MAX_NAME    50
#define MAX_PHONE   15
#define MAX_EMAIL   80
#define FILENAME    "contacts.txt"

typedef struct {
    char nom[MAX_NAME];
    char prenom[MAX_NAME];
    char telephone[MAX_PHONE];
    char email[MAX_EMAIL];
} Contact;

Gestion du tableau dynamique

typedef struct {
    Contact *data;     /* tableau dynamique */
    size_t   count;    /* nombre de contacts */
    size_t   capacity; /* capacité allouée */
} Carnet;

void carnet_init(Carnet *c) {
    c->capacity = 4;
    c->count = 0;
    c->data = malloc(c->capacity * sizeof(Contact));
    if (!c->data) { perror("malloc"); exit(EXIT_FAILURE); }
}

void carnet_free(Carnet *c) {
    free(c->data);
    c->data = NULL;
    c->count = c->capacity = 0;
}

void carnet_ajouter(Carnet *c, const Contact *ct) {
    if (c->count == c->capacity) {
        c->capacity *= 2;
        Contact *tmp = realloc(c->data, c->capacity * sizeof(Contact));
        if (!tmp) { perror("realloc"); exit(EXIT_FAILURE); }
        c->data = tmp;
    }
    c->data[c->count++] = *ct;
}

Contact *carnet_rechercher(Carnet *c, const char *nom) {
    for (size_t i = 0; i < c->count; i++) {
        if (strcmp(c->data[i].nom, nom) == 0)
            return &c->data[i];
    }
    return NULL;
}

Persistance fichier

void carnet_sauvegarder(const Carnet *c, const char *filename) {
    FILE *f = fopen(filename, "w");
    if (!f) { perror("fopen"); return; }
    for (size_t i = 0; i < c->count; i++) {
        fprintf(f, "%s|%s|%s|%s\n",
                c->data[i].nom,
                c->data[i].prenom,
                c->data[i].telephone,
                c->data[i].email);
    }
    fclose(f);
}

void carnet_charger(Carnet *c, const char *filename) {
    FILE *f = fopen(filename, "r");
    if (!f) return;  /* fichier inexistant au premier lancement */
    char ligne[256];
    while (fgets(ligne, sizeof(ligne), f)) {
        Contact ct;
        if (sscanf(ligne, "%49[^|]|%49[^|]|%14[^|]|%79[^\n]",
                   ct.nom, ct.prenom, ct.telephone, ct.email) == 4) {
            carnet_ajouter(c, &ct);
        }
    }
    fclose(f);
}

Le format nom|prenom|tel|email avec séparateur | évite les conflits avec les espaces. sscanf avec %[^|] lit jusqu'au séparateur.

Menu interactif

int main(void) {
    Carnet carnet;
    carnet_init(&carnet);
    carnet_charger(&carnet, FILENAME);

    int choix;
    do {
        printf("\n--- CARNET D'ADRESSES ---\n");
        printf("1. Ajouter un contact\n");
        printf("2. Rechercher par nom\n");
        printf("3. Lister tous\n");
        printf("4. Quitter\n");
        printf("Choix : ");
        if (scanf("%d", &choix) != 1) break;
        while (getchar() != '\n');  /* vider le buffer */

        if (choix == 1) {
            Contact ct;
            printf("Nom : ");      fgets(ct.nom, MAX_NAME, stdin);
            printf("Prénom : ");   fgets(ct.prenom, MAX_NAME, stdin);
            printf("Téléphone : "); fgets(ct.telephone, MAX_PHONE, stdin);
            printf("Email : ");    fgets(ct.email, MAX_EMAIL, stdin);
            /* retirer les '\n' finaux */
            ct.nom[strcspn(ct.nom, "\n")] = 0;
            ct.prenom[strcspn(ct.prenom, "\n")] = 0;
            ct.telephone[strcspn(ct.telephone, "\n")] = 0;
            ct.email[strcspn(ct.email, "\n")] = 0;
            carnet_ajouter(&carnet, &ct);
        } else if (choix == 2) {
            char nom[MAX_NAME];
            printf("Nom à chercher : ");
            fgets(nom, MAX_NAME, stdin);
            nom[strcspn(nom, "\n")] = 0;
            Contact *trouve = carnet_rechercher(&carnet, nom);
            if (trouve)
                printf("→ %s %s, tél: %s, email: %s\n",
                       trouve->prenom, trouve->nom,
                       trouve->telephone, trouve->email);
            else
                printf("Introuvable.\n");
        } else if (choix == 3) {
            for (size_t i = 0; i < carnet.count; i++) {
                printf("%zu. %s %s — %s\n", i+1,
                       carnet.data[i].prenom, carnet.data[i].nom,
                       carnet.data[i].telephone);
            }
        }
    } while (choix != 4);

    carnet_sauvegarder(&carnet, FILENAME);
    carnet_free(&carnet);
    printf("Au revoir !\n");
    return 0;
}
Exemple d'utilisation. L'utilisateur saisit un contact « Traoré Awa 70123456 awa@bit.bf », puis le quitte. Au prochain lancement, le contact est automatiquement chargé depuis contacts.txt. La persistance est assurée entre les sessions.
Exercice d'application. Reprenez la méthodologie ci-dessus avec des valeurs numériques différentes (par exemple un autre jeu de paramètres) et vérifiez que vous arrivez au bon résultat. Puis essayez de refaire l'exercice sans regarder la solution : c'est la meilleure façon de fixer durablement la méthode.

📝 Notes importantes

  • Dépassement de tampon : préférer fgets à gets (supprimé en C11) et strncpy à strcpy pour éviter les débordements.
  • realloc : toujours stocker le résultat dans une variable temporaire pour ne pas perdre le pointeur en cas d'échec.
  • Fichiers : toujours vérifier le retour de fopen et fermer avec fclose (sinon fuite de descripteur).
  • Buffer stdin : vider le buffer après un scanf pour éviter les bugs avec fgets qui récupère le \n.

📚 Pour aller plus loin

  • La persistance binaire via fwrite/fread est plus rapide mais pas portable entre architectures différentes (endianness).
  • Les fichiers CSV sont un format texte universel, lisibles par Excel et Python.
  • Les BDD embarquées (SQLite via libsqlite3) offrent des requêtes SQL et une gestion transactionnelle.
  • La compilation séparée : séparer en carnet.c + carnet.h + main.c facilite la réutilisation et la maintenance.
  • Les outils valgrind et -fsanitize=address détectent les fuites et débordements.
