📋 Énoncé résumé

Le sujet porte sur les structures algébriques fondamentales :

  1. vérifier que (𝒵, +) est un groupe abélien ;
  2. étudier l'anneau 𝒵/n𝒵 pour n = 12 (tables, éléments inversibles) ;
  3. montrer que le corps ℱ5 est un corps commutatif ;
  4. déterminer les sous-groupes de 𝒵/6𝒵.
Définitions. Un groupe (G, ∗) est un ensemble muni d'une loi interne associative, admettant un neutre e, et où tout élément admet un inverse. Si la loi est commutative, le groupe est abélien. Un anneau (A, +, ×) est un groupe abélien pour +, × est associative avec neutre, et × est distributive sur +. Un corps est un anneau commutatif non réduit à {0} où tout élément non nul est inversible pour ×.

💡 Méthodologie

  1. Groupe : vérifier les 4 axiomes (associativité, neutre, inverse, commutativité si abélien).
  2. Anneau quotient 𝒵/n𝒵 : calculer modulo n, identifier les diviseurs de zéro et les inversibles (ceux pgcd(k, n) = 1).
  3. Corps : n premier ⇔ 𝒵/n𝒵 est un corps.
  4. Sous-groupes : utiliser le théorème de Lagrange et la structure des sous-groupes de 𝒵/n𝒵.

✅ Solution détaillée

Question 1 — (𝒵, +) est un groupe abélien

  • Associativité : (a + b) + c = a + (b + c), vrai dans 𝒵.
  • Neutre : 0 + a = a, donc 0 est neutre.
  • Inverse : pour tout a ∈ 𝒵, −a ∈ 𝒵 et a + (−a) = 0.
  • Commutativité : a + b = b + a.

Donc (𝒵, +) est un groupe abélien. Ce n'est pas un corps car la multiplication n'a pas d'inverse pour tous les éléments non nuls (2 n'a pas d'inverse dans 𝒵).

Question 2 — L'anneau 𝒵/12𝒵

Les éléments sont {0, 1, 2, ..., 11}. Les inversibles sont les k premiers à 12 : {1, 5, 7, 11}. Les diviseurs de zéro sont les k non nuls tels que pgcd(k, 12) ≠ 1 : {2, 3, 4, 6, 8, 9, 10}. Par exemple, 3 × 4 = 12 ≡ 0 (mod 12), donc 3 et 4 sont diviseurs de zéro. 𝒵/12𝒵 n'est pas intègre (donc pas un corps).

Question 3 — ℱ5 = 𝒵/5𝒵 est un corps

5 est premier, donc tout élément non nul k ∈ {1, 2, 3, 4} est inversible modulo 5 :

k−11324

Vérification : 2 × 3 = 6 ≡ 1 (mod 5) ✓. L'anneau est commutatif, intègre (pas de diviseurs de zéro car 5 est premier), et tout non-nul est inversible : c'est donc un corps commutatif à 5 éléments.

Question 4 — Sous-groupes de 𝒵/6𝒵

Le groupe (𝒵/6𝒵, +) est cyclique d'ordre 6, donc ses sous-groupes correspondent aux diviseurs de 6 : 1, 2, 3, 6. Les sous-groupes sont :

  • {0} (d'ordre 1)
  • {0, 3} (d'ordre 2, engendré par 3)
  • {0, 2, 4} (d'ordre 3, engendré par 2)
  • {0, 1, 2, 3, 4, 5} = 𝒵/6𝒵 (d'ordre 6)

Cela illustre le théorème de Lagrange : l'ordre de tout sous-groupe divise l'ordre du groupe.

Exemple appliqué. La cryptographie RSA utilise l'anneau 𝒵/n𝒵 avec n = pq produit de deux grands premiers. Les inversibles sont les k tels que pgcd(k, n) = 1, et leur nombre φ(n) = (p−1)(q−1) (indicatrice d'Euler) intervient dans le calcul de l'exposant privé.
Exercice d'application. Reprenez la méthodologie ci-dessus avec des valeurs numériques différentes (par exemple un autre jeu de paramètres) et vérifiez que vous arrivez au bon résultat. Puis essayez de refaire l'exercice sans regarder la solution : c'est la meilleure façon de fixer durablement la méthode.

📝 Notes importantes

  • Diviseurs de zéro vs inversibles : ils s'excluent mutuellement dans un anneau commutatif.
  • Théorème de Lagrange : dans un groupe fini, l'ordre de tout sous-groupe divise l'ordre du groupe.
  • Petit théorème de Fermat : si p est premier et pgcd(a, p) = 1, alors ap−1 ≡ 1 (mod p).
  • Anneau quotient : 𝒵/n𝒵 est un corps si et seulement si n est premier.

📚 Pour aller plus loin

  • Le théorème de Cayley : tout groupe fini d'ordre n est isomorphe à un sous-groupe du groupe symétrique Sn.
  • Les groupes de Lie généralisent les groupes à des structures différentielles (rotations, transformations).
  • Les extensions de corps et la théorie de Galois relient algèbre et résolution d'équations polynomiales.
  • Les codes correcteurs d'erreurs (Reed-Solomon, BCH) sont construits sur des corps finis ℱ2m.
