📋 Énoncé résumé

L'examen Python S1 comporte quatre exercices :

  1. manipulation de variables et types (int, float, str, bool) ;
  2. structures de contrôle : calcul du PGCD et test de primalité ;
  3. fonctions : écrire une fonction est_palindrome(s) ;
  4. listes : implémenter un tri par sélection et une recherche linéaire.
Définition — Python. Python est un langage de programmation interprété, multi-paradigme et à typage dynamique fort. Il a été créé par Guido van Rossum en 1991. Sa syntaxe lisible, sa bibliothèque standard riche et son écosystème (NumPy, Pandas, Django, Flask, TensorFlow) en font le langage privilégié pour l'enseignement, le prototypage, la science des données et le machine learning.

  3. Fonctions : def, return, paramètres par défaut, args/kwargs.

Exercice 2 — PGCD et primalité

def pgcd(a, b):
    """Calcule le PGCD par l'algorithme d'Euclide."""
    while b != 0:
        a, b = b, a % b
    return abs(a)

def est_premier(n):
    """Teste si n est premier."""
    if n < 2:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False
    i = 3
    while i * i <= n:
        if n % i == 0:
            return False
        i += 2
    return True

# Tests
print(pgcd(48, 18))        # 6
print(est_premier(17))     # True
print(est_premier(100))    # False

Exercice 3 — Palindrome

def est_palindrome(s):
    """Vérifie si une chaîne est un palindrome (sans tenir compte des espaces)."""
    s = s.lower().replace(" ", "")
    return s == s[::-1]

# Tests
print(est_palindrome("radar"))         # True
print(est_palindrome("Esope reste ici"))  # True
print(est_palindrome("python"))        # False

L'expression s[::-1] utilise le slicing avec un pas −1 pour inverser la chaîne.

Exercice 4 — Tri par sélection

def tri_selection(arr):
    """Tri par sélection : complexité O(n^2)."""
    n = len(arr)
    for i in range(n):
        # Trouver le minimum dans [i..n-1]
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        # Échanger
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

def recherche_lineaire(arr, x):
    """Recherche linéaire : retourne l'indice de x ou -1."""
    for i, v in enumerate(arr):
        if v == x:
            return i
    return -1

# Tests
print(tri_selection([5, 2, 9, 1, 5, 6]))  # [1, 2, 5, 5, 6, 9]
print(recherche_lineaire([10, 20, 30], 20))  # 1
print(recherche_lineaire([10, 20, 30], 99))  # -1
Exemple appliqué. Python est utilisé pour l'analyse de données : pandas pour les DataFrames, numpy pour les tableaux multidimensionnels, matplotlib pour les visualisations. La fonction enumerate() est idiomatique pour parcourir indices et valeurs simultanément.

📝 Notes importantes

  • Indentation : en Python, l'indentation est syntaxique. Une erreur d'indentation provoque une IndentationError.
  • Typage dynamique : une variable peut changer de type au cours de l'exécution, mais cela nuit à la lisibilité.
  • Mutabilité : list, dict, set sont mutables ; int, float, str, tuple sont immuables.
  • Indexation : Python commence à 0. arr[-1] est le dernier élément.

📚 Pour aller plus loin

  • La compréhension de listes : [x**2 for x in range(10) if x % 2 == 0] est idiomatique.
  • Les générateurs avec yield permettent d'itérer sans stocker toute la séquence en mémoire.
  • La programmation orientée objet : class, __init__, héritage, polymorphisme.
  • Les décorateurs (@staticmethod, @property) modifient le comportement des fonctions.
  • Le module typing introduit les annotations de type (def f(x: int) -> str:) pour la robustesse.
