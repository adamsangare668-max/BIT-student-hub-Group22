📋 Énoncé résumé

Le TP demande de développer un système de gestion d'étudiants en Python. Le cahier des charges impose :

  1. une classe Student avec attributs (id, nom, prénom, notes) ;
  2. une classe StudentRecord pour gérer une collection d'étudiants ;
  3. des méthodes pour ajouter, supprimer, rechercher un étudiant ;
  4. calcul de la moyenne d'un étudiant et du major de promotion ;
  5. persistance des données dans un fichier JSON.
Définition — Programmation orientée objet. La POO organise le code autour de classes qui combinent données (attributs) et comportements (méthodes). Une classe est un « moule » ; un objet est une instance de classe. Les trois piliers sont l'encapsulation (masquer les détails internes), l'héritage (réutiliser et spécialiser) et le polymorphisme (une même interface, des comportements variés).

💡 Méthodologie

  1. Identifier les entités : Student, StudentRecord.
  2. Définir les attributs et leurs types.
  3. Implémenter les méthodes une par une, en testant au fur et à mesure.
  4. Gérer les erreurs : étudiant introuvable, fichier illisible.
  5. Sauvegarder/charger via le module json.

✅ Solution détaillée

Classe Student

class Student:
    """Représente un étudiant avec son identité et ses notes."""

    def __init__(self, student_id, nom, prenom, notes=None):
        self.student_id = student_id
        self.nom = nom
        self.prenom = prenom
        self.notes = notes if notes is not None else []

    def ajouter_note(self, note):
        if 0 <= note <= 20:
            self.notes.append(note)
        else:
            raise ValueError("La note doit être entre 0 et 20")

    def moyenne(self):
        if not self.notes:
            return 0.0
        return sum(self.notes) / len(self.notes)

    def __str__(self):
        return f"[{self.student_id}] {self.prenom} {self.nom} - moy: {self.moyenne():.2f}"

    def to_dict(self):
        return {
            "id": self.student_id,
            "nom": self.nom,
            "prenom": self.prenom,
            "notes": self.notes
        }

    @classmethod
    def from_dict(cls, data):
        return cls(data["id"], data["nom"], data["prenom"], data["notes"])

Classe StudentRecord

import json

class StudentRecord:
    """Gère une collection d'étudiants."""

    def __init__(self):
        self.students = {}  # id -> Student

    def ajouter(self, student):
        if student.student_id in self.students:
            raise ValueError(f"ID {student.student_id} déjà présent")
        self.students[student.student_id] = student

    def supprimer(self, student_id):
        if student_id not in self.students:
            raise KeyError(f"Étudiant {student_id} introuvable")
        del self.students[student_id]

    def rechercher(self, student_id):
        return self.students.get(student_id, None)

    def major(self):
        if not self.students:
            return None
        return max(self.students.values(), key=lambda s: s.moyenne())

    def moyenne_promotion(self):
        if not self.students:
            return 0.0
        moyennes = [s.moyenne() for s in self.students.values() if s.notes]
        return sum(moyennes) / len(moyennes) if moyennes else 0.0

    def sauvegarder(self, fichier):
        with open(fichier, "w", encoding="utf-8") as f:
            json.dump([s.to_dict() for s in self.students.values()], f,
                      ensure_ascii=False, indent=2)

    def charger(self, fichier):
        try:
            with open(fichier, "r", encoding="utf-8") as f:
                data = json.load(f)
            self.students = {s["id"]: Student.from_dict(s) for s in data}
        except FileNotFoundError:
            self.students = {}

    def __iter__(self):
        return iter(self.students.values())

Programme principal (main)

if __name__ == "__main__":
    sr = StudentRecord()
    sr.charger("students.json")

    # Ajout d'étudiants
    s1 = Student(1, "Traoré", "Awa", [12, 15, 18])
    s2 = Student(2, "Kouassi", "Ibrahim", [10, 14, 9])
    s3 = Student(3, "Bamba", "Fatou", [16, 17, 19])
    for s in [s1, s2, s3]:
        try:
            sr.ajouter(s)
        except ValueError as e:
            print(e)

    # Affichage
    for s in sr:
        print(s)

    major = sr.major()
    print(f"\nMajor : {major}")

    # Sauvegarde
    sr.sauvegarder("students.json")

📝 Notes importantes

  • Paramètre par défaut mutable : ne jamais utiliser def f(notes=[]) car la liste est partagée. Utiliser notes=None puis if notes is None: notes = [].
  • Encapsulation : en Python, on préfixe par _ les attributs « protégés » et __ les « privés » (name mangling).
  • Exceptions : toujours catcher spécifiquement (except ValueError), pas except: générique.
  • Encodage : préciser encoding="utf-8" pour gérer les accents.

📚 Pour aller plus loin

  • Les dataclasses (Python 3.7+) génèrent automatiquement __init__, __repr__, __eq__ :
from dataclasses import dataclass, field

@dataclass
class Student:
    student_id: int
    nom: str
    prenom: str
    notes: list = field(default_factory=list)
  • La sérialisation binaire via pickle est plus rapide que JSON mais pas portable.
  • Les BDD (SQLite, PostgreSQL via SQLAlchemy) remplacent le fichier JSON pour les volumes importants.
  • Le module abc permet de définir des classes abstraites avec méthodes abstraites.
  • Les tests unitaires avec unittest ou pytest garantissent la non-régression du code.
