📋 Énoncé résumé

Le sujet traite des fondements de l'analyse réelle :

  1. propriétés des nombres réels (borne sup, complétude) ;
  2. étude de la suite un = (1 + 1/n)n+1 ;
  3. théorème des gendarmes appliqué à vn = sin(n)/n ;
  4. construction de l'ensemble ℛ via les coupures de Dedekind (question de cours).
Définition — Borne supérieure. Soit A une partie non vide majorée de ℛ. La borne supérieure de A, notée sup(A), est le plus petit majorant de A : c'est un réel M tel que (1) ∀ a ∈ A, a ≤ M, et (2) ∀ ε > 0, ∃ a ∈ A, a > M − ε. L'existence de sup(A) pour toute partie non vide majorée est l'axiome de la borne supérieure, qui caractérise ℛ parmi les corps ordonnés.

💡 Méthodologie

  1. Bornes : identifier la propriété caractéristique et utiliser la définition avec ε.
  2. Suite monotone : étudier la monotonie (différence ou rapport un+1/un), puis appliquer le théorème de la limite monotone.
  3. Gendarmes : encadrer la suite entre deux suites de même limite.
  4. Complétude : toute suite de Cauchy réelle converge.

✅ Solution détaillée

Question 1 — Borne sup de A = {1 − 1/n : n ∈ 𝒩*}

A est majorée par 1. Pour montrer que sup(A) = 1, on vérifie les deux propriétés :

  • (1) ∀ n ≥ 1, 1 − 1/n < 1, donc 1 majore A.
  • (2) Soit ε > 0. Pour n > 1/ε, on a 1/n < ε, donc 1 − 1/n > 1 − ε. Ainsi ∃ a ∈ A avec a > 1 − ε.

Donc sup(A) = 1, qui n'appartient pas à A : A n'a pas de maximum.

Question 2 — Étude de un = (1 + 1/n)n+1

On montre (par étude de fonction logarithmique ou par inégalité classique) que un est décroissante et minorée (par 1). Elle converge donc vers une limite ℓ ≥ 1. Or (1 + 1/n)n → e, donc (1 + 1/n)n+1 = (1 + 1/n)n · (1 + 1/n) → e · 1 = e. Ainsi lim un = e.

Comme un > e pour tout n et (1 + 1/n)n < e, on en déduit l'encadrement classique :

(1 + 1/n)n < e < (1 + 1/n)n+1

Question 3 — Limite de vn = sin(n)/n

On encadre : −1/n ≤ sin(n)/n ≤ 1/n. Comme −1/n → 0 et 1/n → 0, le théorème des gendarmes donne vn → 0. La suite oscille autour de 0 avec une amplitude qui décroît en 1/n.

Question 4 — Construction de ℛ (coupures de Dedekind)

Une coupure de Dedekind est un couple (A, B) de parties non vides de 𝒬 telles que A ∩ B = ∅, A ∪ B = 𝒬, et tout élément de A est inférieur à tout élément de B. On identifie alors ℛ à l'ensemble des coupures de Dedekind de 𝒬. Cette construction assure la complétude de ℛ : toute suite de Cauchy réelle converge, ce qui n'est pas le cas dans 𝒬.

Exemple concret. La coupure définissant √2 est A = {q ∈ 𝒬 : q < 0 ou q2 < 2}, B = 𝒬 ∖ A. Cet « objet » n'est pas un rationnel mais appartient bien à ℛ.
Exercice d'application. Reprenez la méthodologie ci-dessus avec des valeurs numériques différentes (par exemple un autre jeu de paramètres) et vérifiez que vous arrivez au bon résultat. Puis essayez de refaire l'exercice sans regarder la solution : c'est la meilleure façon de fixer durablement la méthode.

📝 Notes importantes

  • Borne sup vs max : le maximum doit appartenir à l'ensemble, pas la borne supérieure.
  • Complétude : c'est la propriété clé qui distingue ℛ de 𝒬. 𝒬 est dénombrable mais non complet ; ℛ est complet mais non dénombrable.
  • Suite de Cauchy : ∀ ε > 0, ∃ N, ∀ p, q ≥ N, |up − uq| < ε.
  • Théorème de Bolzano-Weierstrass : toute suite bornée admet une sous-suite convergente.

📚 Pour aller plus loin

  • Les nombres p-adiques 𝒬p complètent 𝒬 pour une autre distance (la valuation p-adique).
  • Les hyperréels étendent ℛ avec des infiniment petits et grands (analyse non standard).
  • L'axiome du choix, l'hypothèse du continu : 2ℵ0 = ℵ1 est indécidable dans ZFC.
  • Les suites réelles sont la base de l'analyse numérique : convergence de méthodes itératives (point fixe, Newton, dichotomie).
