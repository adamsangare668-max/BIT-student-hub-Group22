📋 Énoncé résumé

Le sujet porte sur l'espace vectoriel ℛ3 et le sous-espace E = { (x, y, z) ∈ ℛ3 : x + y + z = 0 }. Il demande :

  1. de montrer que E est un sous-espace vectoriel ;
  2. de donner une base et la dimension de E ;
  3. de calculer le produit matriciel A · B avec A et B données ;
  4. de déterminer le noyau de l'application linéaire définie par A.
Définition — Sous-espace vectoriel. Une partie F d'un espace vectoriel E est un sous-espace vectoriel si et seulement si : (1) F est non vide (le plus simple : 0E ∈ F), (2) F est stable par addition, (3) F est stable par multiplication externe. Ces trois conditions se résument en : ∀ u, v ∈ F, ∀ λ, μ ∈ ℛ, λu + μv ∈ F.

💡 Méthodologie

  1. Sous-espace : vérifier que le vecteur nul appartient à F puis la stabilité par combinaison linéaire.
  2. Base : trouver une famille libre et génératrice de F.
  3. Produit matriciel : utiliser la règle « ligne × colonne ».
  4. Noyau : résoudre le système A·X = 0 par pivot de Gauss.

✅ Solution détaillée

Question 1 — E est un sous-espace vectoriel

Le vecteur nul (0, 0, 0) vérifie 0 + 0 + 0 = 0, donc 0ℛ3 ∈ E. Soient u = (x1, y1, z1) et v = (x2, y2, z2) dans E, et λ, μ ∈ ℛ. Alors :

(λx1 + μx2) + (λy1 + μy2) + (λz1 + μz2)
  = λ(x1 + y1 + z1) + μ(x2 + y2 + z2)
  = λ·0 + μ·0 = 0

Donc λu + μv ∈ E. E est un sous-espace vectoriel de ℛ3.

Question 2 — Base et dimension de E

Les vecteurs de E vérifient z = −x − y, donc tout vecteur s'écrit :

(x, y, z) = (x, y, −x−y) = x·(1, 0, −1) + y·(0, 1, −1)

La famille {(1, 0, −1), (0, 1, −1)} est libre (les deux vecteurs ne sont pas colinéaires) et génératrice de E : c'est une base de E. Donc dim(E) = 2. E est un plan vectoriel passant par l'origine.

Question 3 — Produit matriciel

Soit A = [[1, 2], [3, 4], [5, 6]] (3×2) et B = [[1, 0, 1], [0, 1, 1]] (2×3). Le produit A·B existe et donne une matrice 3×3 :

A·B = [[1, 2, 3],
         [3, 4, 7],
         [5, 6, 11]]

Par exemple, l'élément (1,1) vaut 1·1 + 2·0 = 1, le (1,2) vaut 1·0 + 2·1 = 2, et le (1,3) vaut 1·1 + 2·1 = 3.

Question 4 — Noyau de l'application définie par A

Soit A = [[1, 1, 1], [2, −1, 0]] (matrice 2×3). Le système A·X = 0 s'écrit :

x + y + z = 0
2x − y     = 0  ⇒  y = 2x

En substituant dans la première équation : x + 2x + z = 0 ⇒ z = −3x. Donc ker(A) = { (x, 2x, −3x) : x ∈ ℛ } = vect((1, 2, −3)). Le noyau est une droite vectorielle, engendrée par (1, 2, −3).

Exemple géométrique. Le théorème du rang donne dim(ker A) + dim(im A) = n. Ici n = 3 et dim(ker A) = 1, donc dim(im A) = 2 : l'image est un plan vectoriel, ce qui correspond bien à la matrice 2×3 de rang 2.
Exercice d'application. Reprenez la méthodologie ci-dessus avec des valeurs numériques différentes (par exemple un autre jeu de paramètres) et vérifiez que vous arrivez au bon résultat. Puis essayez de refaire l'exercice sans regarder la solution : c'est la meilleure façon de fixer durablement la méthode.

📝 Notes importantes

  • Vecteur nul : toujours vérifier d'abord que 0 ∈ F avant de tester la stabilité. Cela évite les pièges du type « cercle unité ».
  • Dimension : dim(E) + dim(F) = dim(E ∩ F) + dim(E + F).
  • Produit matriciel : non commutatif en général (AB ≠ BA), mais associatif et distributif.
  • Noyau : ker(A) = ker(ATA) (utile en statistiques pour la régression linéaire).

📚 Pour aller plus loin

  • Les valeurs propres et la diagonalisation permettent d'étudier les applications linéaires de manière simple.
  • La décomposition SVD (Singular Value Decomposition) est centrale en apprentissage automatique (PCA, recommandation, compression).
  • Les espaces de Hilbert étendent l'algèbre linéaire aux espaces de fonctions avec un produit scalaire infini.
  • En informatique graphique, les transformations (rotation, translation, projection) sont des applications linéaires représentées par des matrices 4×4 (coordonnées homogènes).
