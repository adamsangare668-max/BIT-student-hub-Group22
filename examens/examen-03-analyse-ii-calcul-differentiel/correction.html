📋 Énoncé résumé

Le sujet propose une fonction de deux variables f(x, y) = x2y + 3xy2 − 5x + 2y et demande :

  1. les dérivées partielles ∂f/∂x et ∂f/∂y ;
  2. le gradient ∇f(1, 0) ;
  3. les extrema locaux de g(x, y) = x2 + y2 − 2xy − 6x + 4y + 5 ;
  4. le calcul de l'intégrale double ∫∫D (x + y) dx dy où D = [0, 1] × [0, 2].
Définition — Dérivée partielle. La dérivée partielle de f par rapport à x, notée ∂f/∂x, est la dérivée de f par rapport à x en considérant y comme constant. On l'obtient en appliquant les règles de dérivation d'une fonction d'une variable, en traitant y comme un paramètre.

💡 Méthodologie

  1. Dérivées partielles : appliquer les règles usuelles (somme, produit, chaîne) en fixant l'autre variable.
  2. Gradient : vecteur ∇f = (∂f/∂x, ∂f/∂y). Il pointe dans la direction de plus forte pente.
  3. Extrema : annuler le gradient pour trouver les points critiques, puis étudier la matrice hessienne H pour classifier (minimum si det H > 0 et ∂2f/∂x2 > 0, maximum si det H > 0 et ∂2f/∂x2 < 0, point-selle si det H < 0).
  4. Intégrale double : intégrer itérativement par le théorème de Fubini.

✅ Solution détaillée

Question 1 — Dérivées partielles de f

∂f/∂x = 2xy + 3y2 − 5
∂f/∂y = x2 + 6xy + 2

Question 2 — Gradient en (1, 0)

∂f/∂x (1, 0) = 2·1·0 + 3·0 − 5 = −5
∂f/∂y (1, 0) = 1 + 0 + 2 = 3
∇f(1, 0) = (−5, 3)

Question 3 — Extrema de g

∂g/∂x = 2x − 2y − 6
∂g/∂y = 2y − 2x + 4

En résolvant le système ∂g/∂x = 0 et ∂g/∂y = 0, on trouve x = 1, y = −2. La matrice hessienne est :

H = [ 2  −2 ]
    [−2   2 ]
det H = 4 − 4 = 0

Le déterminant est nul : le test est non concluant. Cependant, en posant u = x − y, on a g = u2 − 6x + 4y + 5. Le long de la droite x − y = 4 (soit u = 4), g est constante et vaut 16 − 6x + 4(x − 4) + 5 = 5. Il y a donc une droite de points critiques et aucun extremum strict : g présente une vallée.

Question 4 — Intégrale double

∫01 ∫02 (x + y) dy dx
= ∫01 [ xy + y2/2 ]02 dx
= ∫01 (2x + 2) dx
= [ x2 + 2x ]01
= 1 + 2 = 3
Exemple concret. Cette intégrale calcule la masse d'une plaque carrée dont la densité surfacique est ρ(x, y) = x + y. Le résultat 3 (en unités de masse) confirme l'intuition : la densité moyenne sur le domaine [0,1]×[0,2] vaut 3/2 = 1,5 et l'aire vaut 2, donc masse = 3.
Exercice d'application. Reprenez la méthodologie ci-dessus avec des valeurs numériques différentes (par exemple un autre jeu de paramètres) et vérifiez que vous arrivez au bon résultat. Puis essayez de refaire l'exercice sans regarder la solution : c'est la meilleure façon de fixer durablement la méthode.

📝 Notes importantes

  • Ordre d'intégration : Fubini permet d'inverser l'ordre, mais il faut adapter les bornes si le domaine n'est pas rectangulaire.
  • Confusion gradient / dérivée directionnelle : Duf = ∇f · u0 (produit scalaire avec un vecteur unitaire).
  • Hessienne : ne pas oublier le signe de ∂2f/∂x2 pour distinguer minimum et maximum.
  • Changement de variables : pour des domaines circulaires, passer en coordonnées polaires (dx dy = r dr dθ).

📚 Pour aller plus loin

  • Le théorème de Schwarz assure que ∂2f/∂x∂y = ∂2f/∂y∂x lorsque f est de classe C2.
  • Les multiplicateurs de Lagrange permettent d'optimiser sous contrainte g(x, y) = 0 en résolvant ∇f = λ ∇g.
  • Les équations aux dérivées partielles (chaleur, onde, Laplace) généralisent ces notions aux fonctions de plusieurs variables et sont au cœur de la physique.
  • En machine learning, la descente de gradient utilise ∇f pour minimiser une fonction de coût.
