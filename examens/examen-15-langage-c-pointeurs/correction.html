📋 Énoncé résumé

L'examen C propose quatre exercices sur les pointeurs et tableaux :

  1. échanger les valeurs de deux variables via des pointeurs ;
  2. parcourir un tableau via arithmétique de pointeurs ;
  3. implémenter une fonction strlen et strcpy maison ;
  4. manipuler un tableau 2D via pointeur de pointeur.
Définition — Pointeur. Un pointeur est une variable qui contient l'adresse mémoire d'une autre variable. On le déclare avec T *p; où T est le type pointé. L'opérateur & (adresse) donne l'adresse d'une variable ; l'opérateur * (déréférencement) accède à la valeur pointée. Les pointeurs permettent le passage par adresse, l'allocation dynamique et la manipulation efficace des tableaux.

💡 Méthodologie

  1. Distinguer adresse, valeur et pointeur.
  2. Arithmétique : p + i avance de i × sizeof(T) octets.
  3. Passage par adresse : modifier une variable dans une fonction.
  4. Tableaux et pointeurs : arr[i] ≡ *(arr + i).

✅ Solution détaillée

Exercice 1 — Échange par pointeurs

#include <stdio.h>

void echanger(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

int main(void) {
    int x = 10, y = 20;
    printf("Avant : x=%d, y=%d\n", x, y);
    echanger(&x, &y);
    printf("Après : x=%d, y=%d\n", x, y);
    return 0;
}

Sortie : Avant : x=10, y=20 puis Après : x=20, y=10. Les modifications sont visibles dans main car on passe les adresses.

Exercice 2 — Parcours par pointeur

#include <stdio.h>

#define N 5

int main(void) {
    int tab[N] = {10, 20, 30, 40, 50};
    int *p;
    int somme = 0;

    /* Parcours par indice */
    for (int i = 0; i < N; i++)
        printf("%d ", tab[i]);
    printf("\n");

    /* Parcours par pointeur : équivalent */
    for (p = tab; p < tab + N; p++) {
        printf("%d ", *p);
        somme += *p;
    }
    printf("\nSomme = %d\n", somme);

    return 0;
}

L'arithmétique tab + N avance de N × sizeof(int) = 20 octets. On a tab[i] ≡ *(tab + i) ≡ *(i + tab) ≡ i[tab] (cette dernière écriture est valide mais illisible).

Exercice 3 — strlen et strcpy maison

#include <stdio.h>

/* Longueur d'une chaîne (sans le '\0') */
size_t mon_strlen(const char *s) {
    const char *p = s;
    while (*p != '\0')
        p++;
    return p - s;  /* différence de pointeurs = nombre d'éléments */
}

/* Copie de src vers dst (dst doit être assez grand) */
char *mon_strcpy(char *dst, const char *src) {
    char *ret = dst;
    while ((*dst++ = *src++) != '\0')
        ;
    return ret;
}

int main(void) {
    char s[] = "Bonjour";
    char copie[100];

    printf("Longueur : %zu\n", mon_strlen(s));  /* 7 */
    mon_strcpy(copie, s);
    printf("Copie : %s\n", copie);              /* Bonjour */
    return 0;
}

L'astuce (*dst++ = *src++) != '\0' copie le caractère, incrémente les deux pointeurs, et teste la valeur copiée — tout en une seule ligne, idiome classique du C.

Exercice 4 — Tableau 2D via pointeur de pointeur

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int lignes = 3, cols = 4;
    int **mat = malloc(lignes * sizeof(int *));

    for (int i = 0; i < lignes; i++) {
        mat[i] = malloc(cols * sizeof(int));
        for (int j = 0; j < cols; j++)
            mat[i][j] = i * cols + j;
    }

    /* Affichage */
    for (int i = 0; i < lignes; i++) {
        for (int j = 0; j < cols; j++)
            printf("%3d ", mat[i][j]);
        printf("\n");
    }

    /* Libération */
    for (int i = 0; i < lignes; i++)
        free(mat[i]);
    free(mat);

    return 0;
}

La mémoire est allouée ligne par ligne, ce qui permet des « tableaux irréguliers » (jagged arrays) où chaque ligne a une taille différente.

Exemple appliqué. Les pointeurs de fonction (int (*f)(int, int)) sont utilisés pour les callbacks, par exemple qsort de la bibliothèque standard : qsort(tab, n, sizeof(int), comparateur); où comparateur est une fonction int (*)(const void *, const void *).
Exercice d'application. Reprenez la méthodologie ci-dessus avec des valeurs numériques différentes (par exemple un autre jeu de paramètres) et vérifiez que vous arrivez au bon résultat. Puis essayez de refaire l'exercice sans regarder la solution : c'est la meilleure façon de fixer durablement la méthode.

📝 Notes importantes

  • Pointeur non initialisé : son déréférencement est un comportement indéfini (segfault probable).
  • Fuite mémoire : chaque malloc doit avoir un free correspondant.
  • const : qualifier en const les paramètres non modifiés pour la sûreté et l'auto-documentation.
  • Tableaux vs pointeurs : un tableau n'est pas un pointeur (sizeof diffère), mais il se décompose en pointeur sur sa première élément lorsqu'il est utilisé dans une expression.
