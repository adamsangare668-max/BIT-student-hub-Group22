📋 Énoncé résumé

L'examen d'Architecture des Ordinateurs comporte quatre parties :

  1. décrire le cycle Fetch-Décode-Exécute d'un processeur ;
  2. expliquer la hiérarchie mémoire et calculer un temps d'accès moyen ;
  3. analyser un programme assembleur simple (somme de tableau) ;
  4. comparer les modes d'adressage (immédiat, direct, indirect, indexé).
Définition — Cycle d'instruction. Le processeur exécute chaque instruction machine en trois étapes : (1) Fetch (recherche) : charger l'instruction depuis la mémoire à l'adresse pointée par le compteur ordinal (PC/IP) ; (2) Décode : identifier l'opcode et les opérandes ; (3) Exécute : réaliser l'opération (calcul, accès mémoire, saut). Le PC est ensuite incrémenté (ou mis à jour en cas de branchement).

💡 Méthodologie

  1. Cycle : décrire les trois phases et le rôle des registres (PC, IR, accumulateur).
  2. Hiérarchie : registres → cache L1/L2/L3 → RAM → SSD/HDD, du plus rapide/petit au plus lent/grand.
  3. Temps moyen : T = h · Tcache + (1 − h) · TRAM, où h est le taux de succès (hit rate).
  4. Assembleur : suivre les registres et comprendre chaque instruction.

✅ Solution détaillée

Question 1 — Cycle Fetch-Décode-Exécute

Le processeur répète indéfiniment :

  1. Fetch : l'adresse contenue dans PC est envoyée sur le bus d'adresse ; la mémoire renvoie l'instruction sur le bus de données ; elle est stockée dans le registre d'instruction (IR). PC est incrémenté de la taille de l'instruction (4 octets en MIPS).
  2. Décode : l'unité de contrôle identifie l'opcode (les 6 premiers bits en MIPS) et les opérandes (registres source/destination, immédiat, offset). Elle active les signaux de contrôle appropriés (ALU, mux, lecture/écriture registre).
  3. Exécute : l'ALU réalise l'opération (addition, soustraction, ET logique, etc.), ou la mémoire est lue/écrite, ou le PC est modifié (saut, branchement conditionnel).

Le résultat est écrit dans le registre destination, puis le cycle reprend. Sur un processeur pipeliné, plusieurs instructions chevauchent ces étapes (une par étape), ce qui multiplie le débit.

Temps d'accès moyen avec cache : si le taux de succès du cache L1 est h = 0,95, TL1 = 2 ns, TRAM = 100 ns :

Tmoy = 0,95 × 2 + 0,05 × 100
       = 1,9 + 5 = 6,9 ns

Soit environ 3,5× plus lent que le cache seul, mais 14× plus rapide que la RAM seule. La localité spatiale et temporelle des programmes permet d'atteindre ces 95 % de succès.

Question 3 — Programme assembleur (somme de tableau)

;; MIPS : somme des éléments d'un tableau de 10 entiers
.data
tab:  .word 5, 12, 8, 3, 17, 9, 4, 6, 11, 2
.text
main:
    la   $t0, tab      ; $t0 = adresse du tableau
    li   $t1, 0        ; $t1 = somme = 0
    li   $t2, 0        ; $t2 = compteur i = 0
    li   $t3, 10       ; $t3 = taille du tableau
boucle:
    bge  $t2, $t3, fin ; si i >= 10, sortir
    lw   $t4, 0($t0)   ; $t4 = tab[i]
    add  $t1, $t1, $t4 ; somme += $t4
    addi $t0, $t0, 4   ; avancer le pointeur (4 octets)
    addi $t2, $t2, 1   ; i++
    j    boucle
fin:
    move $a0, $t1
    li   $v0, 1
    syscall            ; afficher la somme (77)

Le résultat est 5+12+8+3+17+9+4+6+11+2 = 77.

Exemple appliqué. Le mode indexé est fondamental pour parcourir un tableau : lw $t4, 0($t0) lit tab[i], puis addi $t0, $t0, 4 passe à tab[i+1]. C'est exactement ce que font les boucles for en C après compilation.

📝 Notes importantes

  • Pipeline : les aléas (data, contrôle, structurel) peuvent imposer des bulles (stalls) et réduire les performances.
  • Principe de localité : spatial (données proches) et temporel (données réutilisées). Les boucles en sont la meilleure illustration.
  • Endianness : little-endian (x86, ARM par défaut) ou big-endian (réseaux, certains DSP). Important pour la sérialisation.
  • Alignement : lire un int à une adresse non multiple de 4 peut causer une exception ou une baisse de perf.

📚 Pour aller plus loin

  • Les architectures superscalaires, out-of-order et prédiction de branchement augmentent l'IPC (instructions par cycle).
  • Les GPU et leurs milliers de cœurs SIMD sont spécialisés dans le parallélisme de données.
  • La mémoire virtuelle et la pagination permettent d'exécuter des processus plus grands que la RAM physique.
  • L'assembleur RISC-V, ouvert et modulaire, est de plus en plus enseigné en remplacement de MIPS.
  • L'émulateur RARS/MARS permet d'exécuter du code MIPS pour apprendre en pratique.
