📋 Énoncé résumé

L'examen de logique combinatoire propose :

  1. simplifier l'expression F(A,B,C) = ∑ m(1, 3, 5, 7) par Karnaugh ;
  2. concevoir un additionneur complet 1 bit ;
  3. concevoir un décodeur 3 vers 8 ;
  4. analyser un multiplexeur 4 vers 1.
Définition — Circuit combinatoire. Un circuit logique combinatoire est un circuit dont les sorties ne dépendent que des entrées présentes (pas de mémoire). Il se décrit par une fonction booléenne et peut être réalisé avec des portes logiques (ET, OU, NON, XOR, NAND, NOR). À l'inverse, un circuit séquentiel possède des éléments mémoire (bascules) et son état dépend des entrées passées.

💡 Méthodologie

  1. Table de vérité : lister toutes les combinaisons d'entrées et les sorties.
  2. Forme canonique : somme de mintermes (∑ m(...)) ou produit de maxtermes.
  3. Simplification : table de Karnaugh ou algèbre de Boole.
  4. Implémentation : choix des portes, optimisation du nombre de circuits intégrés.

✅ Solution détaillée

Question 1 — Simplification par Karnaugh de F(A,B,C) = ∑ m(1, 3, 5, 7)

Table de vérité :

ABCF
0000
0011
0100
0111
1000
1011
1100
1111

Table de Karnaugh (lignes AB, colonnes C) :

AB \ C01
0001
0101
1101
1001

Les 4 « 1 » de la colonne C = 1 forment un groupe de 4, ce qui élimine A et B. La fonction simplifiée est :

F = C

Vérification : F vaut 1 si et seulement si C = 1, indépendamment de A et B. Effectivement, les mintermes m(1, 3, 5, 7) correspondent à C = 1.

Question 2 — Additionneur complet 1 bit

Un additionneur complet calcule S = A ⊕ B ⊕ Rin (somme) et Rout = AB + Rin(A ⊕ B) (retenue sortante).

00000

01010
01101
10010
10101
11001
11111

Implémentation : 2 XOR (pour S), 2 AND et 1 OR (pour Rout). En cascadant n additionneurs complets, on obtient un additionneur n bits à propagation de retenue (ripple-carry adder).

Question 3 — Décodeur 3 vers 8

Un décodeur 3 vers 8 possède 3 entrées A, B, C et 8 sorties Y0...Y7, une seule étant active (à 1) selon le code binaire en entrée.

Y0 = ¬A · ¬B · ¬C    (000)
Y1 = ¬A · ¬B · C      (001)
Y2 = ¬A · B · ¬C       (010)
Y3 = ¬A · B · C         (011)
Y4 = A · ¬B · ¬C        (100)
Y5 = A · ¬B · C          (101)
Y6 = A · B · ¬C           (110)
Y7 = A · B · C             (111)

Implémentation : 8 portes AND à 3 entrées, 3 inverseurs. C'est l'outil de base pour sélectionner une adresse mémoire parmi 2n.

Question 4 — Multiplexeur 4 vers 1

Un MUX 4×1 possède 4 entrées de données D0...D3, 2 entrées de sélection S1, S0, et 1 sortie Y. La sortie recopie l'entrée sélectionnée par le code binaire S1S0.

Y = ¬S1 · ¬S0 · D0 + ¬S1 · S0 · D1
  + S1 · ¬S0 · D2 + S1 · S0 · D3
S1S0Y
00D0
01D1
10D2
11D3

Les MUX sont utilisés pour la sélection de données, la conversion parallèle ↔ série, et même l'implémentation de fonctions booléennes arbitraires (en connectant les Di à 0 ou 1 selon la table de vérité).

Exemple appliqué. L'UAL (Unité Arithmétique et Logique) d'un processeur utilise des MUX pour choisir entre plusieurs opérations (addition, soustraction, ET, OU) en fonction du code-op. Les FPGAs modernes sont essentiellement composés de tables de correspondance (LUT) qui sont des MUX reconfigurables.

📝 Notes importantes

  • Théorème de De Morgan : ¬(A·B) = ¬A + ¬B et ¬(A+B) = ¬A · ¬B. Permet de convertir ET/OU.
  • Universalité : NAND (ou NOR) seul suffit à exprimer toute fonction booléenne.
  • Hazards : les aléas de commutation sont évités par ajout de termes consensus dans la table de Karnaugh.
  • Propagation : chaque porte a un temps de propagation (typiquement 1-10 ns), critique pour la fréquence d'horloge.

📚 Pour aller plus loin

  • Les PLD, CPLD, FPGA permettent de réaliser des circuits combinatoires reconfigurables.
  • Les langages VHDL et Verilog décrivent les circuits numériques pour la synthèse.
  • La logique tri-state (3 états : 0, 1, haute impédance) permet de partager un bus entre plusieurs émetteurs.
  • La logique dynamique (horlogée) est plus rapide mais consomme plus en transition ; elle équipe les processeurs modernes.
  • Les VHDL-2008 et SystemVerilog modernisent la conception pour la vérification formelle.
