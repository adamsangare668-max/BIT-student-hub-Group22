📋 Énoncé résumé

Le QCM comporte 20 questions à choix multiples, chacune avec 4 propositions dont une seule est correcte. Les thèmes couvrent :

  • les structures de contrôle (si, pour, tant que) ;
  • la complexité asymptotique (O(n), O(log n), O(n2)) ;
  • les types de données (entier, réel, booléen, tableau) ;
  • les algorithmes classiques (tri, recherche, récursivité).
Définition — Complexité asymptotique. La complexité temporelle d'un algorithme mesure le nombre d'opérations élémentaires en fonction de la taille n de l'entrée. On utilise la notation grand-O : f(n) = O(g(n)) signifie qu'il existe un rang n0 et une constante C tels que ∀ n ≥ n0, |f(n)| ≤ C·g(n). Les complexités courantes par ordre croissant : O(1) < O(log n) < O(n) < O(n log n) < O(n2) < O(2n) < O(n!).

💡 Méthodologie

  1. Lire attentivement chaque question et toutes les propositions avant de choisir.
  2. Éliminer les réponses manifestement fausses.
  3. Tester mentalement l'algorithme sur un petit exemple.
  4. Vérifier les cas limites (n = 0, tableau vide, etc.).

✅ Solution détaillée

Question 1 — Quelle est la complexité de la recherche dichotomique ?

A. O(1) — B. O(log n) ✓ — C. O(n) — D. O(n2)

Justification : à chaque étape, on divise la taille du tableau par 2, donc après k étapes, il reste n/2k éléments. On s'arrête quand n/2k = 1, soit k = log2(n).

Question 2 — Quelle structure de contrôle utiliser pour répéter n fois une action ?

A. Tant que — B. Si...Sinon — C. Pour ✓ — D. Selon

Justification : la boucle Pour est dédiée au cas où le nombre d'itérations est connu à l'avance. Tant que est pour une condition d'arrêt dynamique.

Question 3 — Que vaut 5 mod 3 ?

A. 1 — B. 2 ✓ — C. 3 — D. 0

5 = 1 × 3 + 2, donc 5 mod 3 = 2.

Question 4 — Quelle est la complexité du tri à bulles ?

A. O(n) — B. O(n log n) — C. O(n2) ✓ — D. O(2n)

Deux boucles imbriquées : (n−1) + (n−2) + ... + 1 = n(n−1)/2 = O(n2).

Question 5 — Quel est le résultat de l'algorithme suivant pour n = 4 ?

s ← 0
Pour i de 1 à n Faire
  s ← s + i
FinPour

A. 4 — B. 6 — C. 10 ✓ — D. 24

s = 1 + 2 + 3 + 4 = 10. C'est la somme des n premiers entiers = n(n+1)/2.

Question 6 — Que fait l'algorithme suivant ?

Tant que n ≠ 0 Faire
  r ← n mod 2
  Afficher r
  n ← n div 2
FinTantQue

A. Affiche n en base 2 (à l'envers) ✓ — B. Calcule la parité — C. Calcule n! — D. Boucle infinie

Justification : on récupère les bits successifs de n par division par 2. Pour n = 13, on obtient 1, 0, 1, 1 (qui est 1101 à l'envers, soit 13 en binaire).

Questions 7 à 20 — Synthèse

Les questions 7 à 20 portent sur :

  • Q7-10 : récursivité (factorielle, Fibonacci, tours de Hanoï, PGCD).
  • Q11-14 : tableaux (parcours, recherche, min/max, moyenne).
  • Q15-17 : tris (sélection, insertion, fusion) et leurs complexités.
  • Q18-20 : types abstraits (pile, file, liste chaînée) et opérations.

Score attendu : 16/20 pour un étudiant moyen, 20/20 pour un excellent.

Exercice bonus. Combien d'instructions sont exécutées par l'algorithme de tri par sélection sur un tableau de taille n ? Réponse : (n−1) + (n−2) + ... + 1 = n(n−1)/2 comparaisons, soit O(n2).
Exemple illustratif. Pour bien comprendre, essayez de reproduire le raisonnement sur un cas concret (avec vos propres valeurs) et vérifiez chaque étape. Cette démarche active d'apprentissage est beaucoup plus efficace que la simple lecture passive de la solution.

📝 Notes importantes

  • Lecture : attention aux négations (« laquelle est fausse », « ne fait pas ») qui inversent la logique.
  • Calcul mental : s'entraîner à évaluer des boucles sur des petits exemples pour gagner du temps.
  • Complexités : connaître le tableau des complexités usuelles (tri, recherche, PGCD, exponentiation rapide).
  • Gestion du temps : 1 minute par question en moyenne, réserver 5 minutes pour la relecture.

📚 Pour aller plus loin

  • La théorie de la complexité classe les problèmes en P, NP, NP-complet (voyageur de commerce, sac à dos, SAT).
  • Le problème P = NP est l'un des 7 problèmes du millénaire (1 million de dollars à la clé).
  • Les structures de données avancées (arbres, tas, hash maps) offrent des compromis entre opérations (insertion, recherche, suppression).
  • Les algorithmes probabilistes (Las Vegas, Monte Carlo) contournent certaines bornes déterministes.
